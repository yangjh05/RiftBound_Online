# 실전 실패 국면을 학습에 연결하기

## 적용 범위

관리자가 선택한 AI 경기 보고서를 재생하여 **대안 검증 후보**로 가져옵니다. 제출자의 설명을 정답으로 사용하지 않으며, 모든 사용자 보고서를 자동으로 학습에 넣지도 않습니다. 보고서 제공자의 동의와 사용 범위를 확인한 자료만 명시적으로 가져오십시오.

다음 네 유형을 카드 이름별 예외 없이 찾습니다.

| 유형 | 비교 질문 |
| --- | --- |
| 전투 재평가 | 불리해진 전투에서 통과할지, 대응 주문에 자원을 쓸지 |
| 점거 차단 대상 | 어느 적을 제거해야 상대의 다음 득점을 막을 수 있는지 |
| 턴 전체 전개 | 큰 유닛 한 장과, 여러 카드를 이어 정복하는 전개 중 무엇이 나은지 |
| 반응 자원 보존 | 비싼 제거/추가 이득과, 저렴한 제거 후 남는 자원 중 무엇이 나은지 |

추출 결과는 가설입니다. 예를 들어 싸다는 이유만으로 낮은 비용 주문을 정답으로 지정하지 않습니다. 지불과 대상 선택, 후속 행동, 상대 대응을 포함한 기존 paired terminal audit를 통과해야 학습 근거가 생깁니다. 강제 통과, 해결 중인 비용 지불, 비교할 수 없는 복잡한 국면은 임의의 잘못된 행동으로 분류하지 않습니다.

## 가져오기

```powershell
node --require ./scripts/tf-node-compat.cjs scripts/live-game-curriculum.mjs import --directory data/ai-live-games-20260922 --report <보고서.json> --payment-model src/ai/checkpoints/champion.json --sequences 137,166,180,181
```

`--sequences`를 생략하면 전체 AI 행동에서 후보를 찾습니다. 기본 상한은 대안 쌍 32개입니다. `--payment-model`은 예전 로그의 추상적인 비용 지불 명령을 재생하는 데 사용하며, 사용한 모델의 해시를 검증 기록에 남깁니다.

- 처음부터 모든 성공 명령을 재생합니다. 명령 유실/순서 불일치/행동자 불일치/상태 불일치/선택 안전 위반이 있으면 가져오기를 중단합니다.
- 보존된 명령 프레임과 최종 상태의 의미상 게임 정보를 비교합니다. 시각 기반 ID까지 동일한 원본 스냅샷 재현을 주장하지는 않습니다.
- 완료되지 않은 경기는 이 경로에서 학습하지 않고 수동 분석 대상으로 남깁니다.
- 명령과 초기 상태로 원본 경기 ID를 계산합니다. 같은 보고서의 재업로드나 설명 변경은 새 학습 경기로 늘어나지 않습니다.
- 원본 경기 단위의 고정 해시로 학습/독립 평가 역할을 나눕니다. 같은 경기의 다른 국면이나 시드가 두 역할에 나뉘지 않습니다.
- 계정 정보, 오류 설명, UI 진단 자료는 학습 아카이브에 복사하지 않습니다. 상대 비공개 손패와 주 덱의 실제 카드 정체는 감추고 기존 추정 덱/공유 난수 비교를 사용합니다.
- JSON으로 저장할 때 사라지는 챔피언/전장 유닛/처리 중 카드의 공유 참조를 별도 경로 표로 보존해 워커에서 복원합니다.

## 대안 검증

```powershell
node --require ./scripts/tf-node-compat.cjs scripts/live-game-curriculum.mjs audit --directory data/ai-live-games-20260922 --maximum-jobs 4 --processes 1
node --require ./scripts/tf-node-compat.cjs scripts/live-game-curriculum.mjs status --directory data/ai-live-games-20260922
```

특정 장면만 검증하려면 audit에도 `--sequences 166`처럼 지정할 수 있습니다. 기본 한 작업은 선택 행동과 대안 하나를 32개의 사전 고정된 난수 조건에서 비교합니다. 상대 손패 추정과 난수 조건을 양쪽에 공유하고 상대의 후속 행동도 진행합니다. 작업당 최대 1,200단계이며, 미완료/무효 비교는 승리나 정답으로 바꾸지 않습니다.

완료된 4시드 묶음은 재실행 시 재사용합니다. 끝난 최종 비교에 결과를 보고 시드를 더 붙이지 않습니다. 기본 워커는 로컬 1개이며 최대 4개까지 명시적으로 선택할 수 있습니다. 긴 실전 국면은 비교에 상당한 시간이 걸릴 수 있습니다.

아직 결과가 없는 후보, 잘못된 근거, 엔진/원본/행동/시드 계획이 바뀐 자료는 학습에 들어가지 않습니다. 결과가 불확실한 것은 실패로 단정하지 않습니다. 실전 제보 자료에는 모집단 표본 확률이 없으므로 일반 승률이나 전체 국면에 대한 통계적 인증으로 사용하지 않습니다.

## 적응형 학습에 연결

새 적응형 학습 실행의 설정에 다음 항목을 추가합니다.

```json
{
  "liveGameCurriculumDirectory": "C:/Users/USER/Documents/RiftBound_Online/data/ai-live-games-20260922"
}
```

이 항목을 생략하면 기존 동작을 유지합니다. **이미 시작한 실행의 config.json을 직접 수정하지 마십시오.** 적응형 학습은 설정 해시를 고정하며 변경된 설정으로 재개하지 않습니다. 기존 체크포인트를 이어 쓰려면 프로젝트의 검증된 체크포인트 이전 절차로 새 실행을 구성해야 합니다. 이 기능 설치 자체가 진행 중인 실행을 재시작하거나 설정을 바꾸지는 않습니다.

연결된 실행에서는 매 반복 시작 시 검증이 끝난 실전 자료를 최대 8경기까지 순환 선택합니다. 원본 및 근거 파일 해시와 목록을 그 반복의 계획에 고정합니다. 비교가 나중에 완료된 자료는 다음 반복부터 고려됩니다.

체크포인트 이전으로 새 실행을 시작할 때는 `initial-live-game-plan.json.gz`에 최초 근거 목록을 먼저 고정하고, 이미 검증된 학습 역할 자료로 평가기를 1 epoch 갱신합니다. 이 결과는 `initial-q.json.gz`의 `liveGameInitialization`에 표본 수·손실·전후 모델 해시와 함께 저장됩니다. 중단 후 재개해도 저장된 갱신을 중복 적용하지 않습니다. 행동 정책 해시가 변하거나 손실이 유한하지 않으면 저장하지 않습니다.

기본 경로에서는 이 자료를 **평가기의 고정 후속 정책 Q 학습**에만 추가합니다. 과거 AI의 행동 확률과 순환 메모리를 추측해 자기대전 PPO 데이터로 위장하지 않습니다. 아래의 별도 행동 교정 프로토콜을 활성화하지 않으면 행동 정책에 직접 반영되지 않습니다. 자료가 추가됐다는 이유만으로 실력이 향상됐다고 판단하면 안 됩니다.

## 독립 평가

평가 역할의 원본 경기는 학습에서 차단합니다. 후보 체크포인트에 `liveGameRegression`이 함께 저장됩니다.

- 유형별 비교 수, 검증상 더 나은/나쁜 선택, 측정 불가 선택을 구분합니다.
- 최초 가설과 반대 방향으로 검증되면 판정도 반대로 합니다.
- 신뢰 구간이 겹치거나 후보가 비교하지 않은 제3의 수를 선택하면 측정 불가입니다.
- 별도 평가 경기가 없으면 `unavailable-no-held-out-audits`입니다. 오류율 0%로 표시하지 않습니다.
- 과거 경기의 순환 메모리가 없으므로 cold-start 진단이며, 자동 승격 근거가 아닙니다. 최종 배포는 기존 전체 덱/선후공 승률 검증을 계속 통과해야 합니다.

이번 카이사 경기 한 개는 고정 분할상 학습 역할입니다. 이 경기의 다른 장면을 독립 평가 자료라고 부르지 않습니다. 실제 정책 개선 수치를 보고하려면 별도의 평가 역할 경기를 더 확보해야 합니다.

## 실제 행동 교정 경로

`scripts/live-policy-correction.mjs`는 `live-policy-protocol.json`으로 별도 활성화합니다. 진행 중인 `config.json`은 수정하지 않습니다. 최초 활성화는 현재 저장 회차 이후만 허용하고, 프로토콜 해시를 고정합니다. 이후 32회차마다 다음 순서로 실행합니다.

1. 학습 역할 실전 경기 최대 8개·대안 쌍 최대 32개와 **현재 모델의 정확한 가중치**를 고정합니다. 이전 휴리스틱 감사 결과를 행동 교정 근거로 재사용하지 않습니다.
2. 양쪽 플레이어가 고정된 현재 신경망으로 후속 수를 두도록 별도 감사합니다. 32개 선별 시드와 겹치지 않는 128개 최종 시드를 시작 전에 저장합니다. 선별 기준을 통과한 쌍만 최종 감사를 진행합니다.
3. 모든 시드에서 양쪽 분기가 자연 종료되고, 모든 대안 쌍에 대한 다중 비교를 보정한 99% 가족별 신뢰 하한이 +0.02를 넘어야 교정을 허용합니다. 예산이 끝나도 애매하면 종료하며, 유리해질 때까지 시드를 추가하지 않습니다.
4. 기존 `policyConditionedActionCorrectionTrajectories`의 모델·행동·정보집합 일치 검증을 다시 통과한 자료만 preference 학습에 넣습니다. 1 epoch, 학습률 0.00005, 최대 32개 교정, 기존 정책에 대한 KL 벌점 0.1을 사용합니다. 과거 경기 PPO 손실과 가치·진단·비공개 손패 학습은 비활성입니다.
5. 교정과 별개로 생성한 5덱 × 2경기의 전술 장면을 검사합니다. 최소 32개, 최대 256개 장면에서 평균 KL 0.01·최대 KL 0.05·정답 일치율 하락 2%p·모방 손실 증가 0.02 이내여야 합니다. 부족하거나 실패하면 원래 가중치를 유지합니다. 이 검사는 전술 휴리스틱과의 일치 및 국소 안정성 검사이며, 실전 승률 향상의 증명은 아닙니다.
6. 가중치가 실제 변경된 경우 동일 출발 모델의 교정 켬/끔으로 40경기 진단을 수행합니다. 덱·좌석·선후공·난수 스트림을 균형 있게 비교합니다. 작은 진단 대국은 자동 승격 근거가 아니며, 기존 정식 챔피언 평가는 그대로 유지합니다.
7. 검사를 마친 정책으로 **새 자가대국을 수집한 뒤** PPO를 계속합니다. 중단 후 재개 시 고정된 시드와 완료한 감사 샤드를 재사용합니다.
