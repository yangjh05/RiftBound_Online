# 오리진 공식 한국어 번역 대조 기록

확인일: 2026-09-22. 이 문서는 프로젝트의 대조 검토이며 Riot Games가 발행한
한국어 정오표가 아닙니다.

공식 한국어 갤러리의 오리진 352개 이미지 레코드(기본 298종 포함)와 증명의
전장 24종을 수록했습니다. 앱에만 있는 일러스트 변형 7개는 대응 기본 카드의
문구를 상속하고, 서명판 번호의 `s`는 공식 갤러리의 `*`에 연결했습니다.
한국 출시 발표에서 확인한 한복 아리 1종도 별도로 수록했습니다.
총 396개 번역 항목 중 현재 등록 카드에 적용되는 항목은 384개입니다.
등록 카드 중 동일 일러스트의 한국어 이미지가 확인된 377개에 한국어 이미지를 적용합니다.

공식 갤러리의 한국어·영어 효과 문구를 카드 번호별로 전수 대조했습니다.
차이가 있는 카드는 정오표와 비교하고, 아래 교정 대상 및 주요 용어는 공식
한국어 카드 이미지에서도 확인했습니다. 모든 실제 인쇄물을 판독한 것은
아니며, 이후 발표될 정오표나 이미지 변경까지 보장하는 검토는 아닙니다.

## 비공식 교정 적용

화면에는 `비공식 번역`과 `공식 번역 오역: 사유`를 먼저 표시하고 교정한 효과
전문을 제공합니다. 잘못된 공식 문구와 카드별 근거 URL도 데이터에 보존합니다.
문맥상 모호한 두 카드는 `공식 번역 해석 주의`로 별도 표시합니다.

| 카드 | 확인한 문제 | 적용할 의미 |
|---|---|---|
| 구미호 — OGN-255, 303, 303 서명판, 한국 한정 303a | 인쇄 문구에 ‘이번 턴’ 누락 | 위력 감소는 해당 턴까지만 적용하며 최저 위력은 1입니다. |
| 세트, 두목 — OGN-240 및 240a | 영문에 없는 ‘다른’ 추가 | 해당 전장의 버프된 아군을 세며, 버프된 세트 자신도 포함합니다. |
| 최후의 숨결 — OGN-260 | 피해를 입히는 유닛 주어 누락 | 준비시킨 아군 유닛이 자신의 위력만큼 피해를 입힙니다. 주문 자체가 피해원이 아닙니다. |
| 쌍권총 난사 — OGN-268 | ‘한 전장’ 범위 누락 | 선택한 한 전장의 모든 적 유닛에게 피해를 입힙니다. 전체 전장을 합치지 않습니다. |
| 폭풍의 인장 — OGN-287 | 정오표의 선택 절차 설명이 임의 여부로 읽힘 | 룬 재활용은 필수이며 규칙상 대상을 선택하는 효과가 아닙니다. |

앞의 두 카드는 참고 게시물에서 지적한 내용과 일치합니다. 최후의 숨결은
이번 대조에서 추가로 확인한 피해 주체 누락입니다. 쌍권총 난사와 폭풍의 인장은
확정 오역이 아니라 해석 주의로 분류하고 오해를 막기 위한 비공식 해석을
제공합니다. 이 프로젝트의 교정은 공식 한국어 정오표가 아닙니다.

구미호 303번과 서명판의 갤러리 설명에는 ‘이번 턴’이 있지만 이미지에는
없습니다. 따라서 설명을 인쇄 원문으로 덮어쓰지 않고 둘 다 저장했습니다.
노란색 세트의 교정은 신체 영역의 세트(164번)나 전설 우두머리(269번)에
적용하지 않습니다.

## 오역에서 제외한 차이와 남은 해석 주의

티모, 전략가(121번)의 숨겨짐 사용 시 유발 조건, 차원문 구출(102번)의 사용
주체, 유망한 미래(115번)·눈부신 오로라(160번)의 추방 절차, 소나(73번)와
타곤의 봉우리(289번)의 최대 수량 등은 한국어판이 정오표를 반영한 사례입니다.
영어 갤러리에 이전 문장이 남아 있어 생기는 차이를 오역으로 처리하지 않았습니다.

수량이 없는 ‘아군 유닛’·‘적 유닛’은 영문의 복수형을 옮긴 공식 문체일 수
있습니다. 꼬리 천 개 주시자(116번), 웅장한 책략(233번)에 임의로 `1명`을
추가하지 않습니다.

대담한 작전(153번)의 버프 소유격 생략과 선봉대 투구(228번)의 단일 수량
생략은 문맥으로 해석될 여지가 있어 확정 오역으로 분류하지 않았습니다.
그 외 검토한 문구에서 추가로 확정할 규칙 의미 오류는 찾지 못했습니다.

## 번역 가이드 및 자동 검증

한국어 설정에서는 같은 카드 번호·일러스트에 해당하는 공식 한국어 이미지를
사용합니다. 도감, 덱 편집, 게임판, 손패, 선택 창, 확대 보기, 이동 연출에
공통으로 적용합니다. 한국어 이미지가 확인되지 않은 카드는 기존 이미지를
유지합니다. 문구를 기본판에서 상속한 변형 7종도 다른 일러스트로 바꾸지 않습니다.

한국 한정 한복 아리 `OGN-303a/298`는 공식 발표 이미지에서 번호·일러스트·문구를
확인해 등록했습니다. Allen Song의 일러스트이며, 기존 구미호와 같은 공용
효과를 사용합니다. 별도 한국 출시 스냅샷에 발표 원본 URL과 전사 문구를 보존하며,
이미지는 공식 CDN의 영역 표시 옵션으로 카드 바깥 여백만 제외합니다.

공식 카드명·부제·효과를 가져오고 `Fury → 분노`, `Mighty → 위력적`을
가이드와 공통 표시 용어에 반영했습니다. 카드명 `볼리베어, 격노`처럼 공식
고유명사의 ‘격노’는 그대로 유지합니다.

공식 본문의 ‘얻습니다’, 수량 어순, 문장부호는 비공식 문체 정규화로 바꾸지
않습니다. HTML 목록과 자원 기호만 읽을 수 있는 텍스트로 변환합니다.
원자료의 이름·부제·본문·이미지 URL과 페이지 해시를 스냅샷에 보존했습니다.

재생성은 `node scripts/build-official-korean-translations.mjs`, 재생성 결과
확인은 같은 명령의 `--check` 옵션을 사용합니다. `npm run audit:ko`는 원문
보존·오역 표시·변형 상속 검증과 비공식 번역 문체 검증을 모두 실행합니다.
일반 문체 치환 도구는 출처가 기록된 공식 번역 파일을 수정하지 않습니다.

기준 문서는 [한국어 카드 번역 단일 기준](korean-card-translation-style.md)입니다.

## 구현 검증 기록

- 번역·이미지·벤데타 공통 용어 관련 테스트 72개 통과. 가려진 카드의 한국어
  이미지를 노출하지 않는 검사도 통과했습니다.
- 등록 카드 990개의 도감·상세·확대 보기 이름, 효과 문구, 이미지 대응 검사 통과.
  실제 설정에서 한국어 → 영어 → 한국어 전환 및 한복 아리 표시 검사 통과.
- 카드·엔진·규칙 검증, 카드 의미 검증 990종, 변이 검사 3,984개,
  효과 종류 685개, 한국어 원문·용어 감사 통과.
- 회귀 변이 170개, 효과 변이 685개, 합성 상호작용 992개, 고정 시드 게임
  50회와 생성 시나리오 32개 통과.
- 한복 아리 추가 시 기존 학습 카드 순서가 밀리지 않도록 새 번호를 마지막에
  추가했습니다. 기존 모델 복원 및 카드 목록 확장 검사 7개, 카드풀 검사 1개 통과.

`npm run check:no-ai`도 실행했습니다. 단위 검사 1,154개 중 1,143개가 통과했고,
새 카드의 기존 학습 순서 문제 1개와 Node 24/TensorFlow의
`util.isNullOrUndefined` 호환성 문제 10개가 발견되었습니다. 학습 순서 문제를
수정하고 저장소에 이미 있는 `scripts/tf-node-compat.cjs`를 적용해 실패가 발생한
파일들을 다시 실행했으며 총 27개 검사가 통과했습니다. 기본 전체 검사 명령에는
이 호환 설정이 자동 적용되지 않으므로 해당 환경 오류가 남습니다.

전체 브라우저 검사는 199개 중 197개가 통과했습니다. 시간 초과가 발생한
신고 화면·세 번째 전장 표시 검사 2개도 각각 다시 실행해 통과를 확인했습니다.
