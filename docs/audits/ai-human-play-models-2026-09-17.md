# 최근 챔피언과 최신 학습 모델의 사람 대전 연결

- 주소: `http://127.0.0.1:4173/` (로컬 대전 서버)
- 최근 승급 챔피언: **327세대**, 현재 실행의 139회차 체크포인트.
- 최신 완료 학습 모델: **387세대**, 게시 시점 199회차 체크포인트. 시험 대전용이며 승급을 의미하지 않는다.
- 준비를 시작했을 때의 최신 모델 386세대도 보존했다. 게시 모델은 해당 시점의 고정본이며 이후 세대를 자동 게시하는 작업은 추가하지 않았다.

현재 실행의 상태 파일에서 챔피언과 학습 모델 경로를 가져왔다. 챔피언은 평가 23의 저장 경기로 승급 결과를 재검증했다. 해당 평가는 400경기, 관측 승률 59.5%로 통과했다. 이는 당시 챔피언 211세대와의 평가 결과이며 사람 상대 승률이 아니다.

각 학습 아카이브의 `checkpoint`를 변경 없이 사람 대전 전용 데이터 디렉터리 `data/ai/human-play-20260915/candidates`에 JSON으로 게시했다. 모델 내용과 원본 아카이브의 해시를 확인했고 기존 대전용 파일을 유지했다. 학습 상태, 가중치, 평가 결과는 변경하지 않았다.

사람 대전용 `resume/run.json`에 챔피언·학습 모델 역할을 기록했다. 선택 화면은 기존 API의 `activeChampion`과 `activeLearner`를 사용해 ‘최근 승급 챔피언’, ‘최신 학습 모델 · 시험 대전’으로 표시한다. 최신 학습 모델의 챔피언 대비 우위가 미확정이라는 설명도 표시한다.

검증:

- 327·387세대 목록 조회, 역할 표시, 현재 엔진 호환 표시 확인.
- 각 모델 다운로드 HTTP 200 및 다운로드 내용의 SHA-256과 게시 원본 일치 확인.
- 실제 Chromium에서 모델 선택과 로딩, 주사위, 사이드보딩, 챔피언 선택, 멀리건, 본게임 진입 확인. 327세대는 AI가 주사위에 이긴 경우, 387세대는 사람이 이긴 경우를 검증했다. 두 경우 모두 페이지 오류가 없었다.
- UI 파일 구문 검사 통과.

검증 기록: `.tmp-ai-human-play-20260917/publication.json`, `http-verification-latest.json`, `browser-verification.json`, `browser-verification-latest.json`. 로컬 서버는 Normal 우선순위이며 상태는 같은 폴더의 `server.json`에 기록했다.
