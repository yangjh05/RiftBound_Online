## AI 실행 보완

`src/ai/runtime-tactical-review.mjs`를 실제 `turn-worker.mjs`의 신경망/기존 정책 선택 직후에 연결했습니다. 모델 가중치를 바꾸지 않아도 실행하는 행동이 바뀔 수 있습니다. 게임 상태는 복제하고 상대 손/덱 등 비공개 정보는 가린 뒤 실제 엔진으로 비용과 후속 행동을 비교합니다.

- 2초/48회 미리보기 상한, 오류나 예산 소진 시 원래 모델 선택 유지. 개별 미리보기의 중간 강제 종료는 하지 않는 협력적 시간 제한입니다.
- 같은 카드 쌍의 순서 변경은 보드/손/버림 상태가 같고 도메인별 준비 룬이 줄지 않으며 더 많은 룬을 남기는지 확인합니다.
- 비싼 유닛 하나 대신 저렴한 전개와 대응 자원을 남기는 후보를 비교합니다.

- 완전 탐색, 승률 증명 또는 모든 실수 방지는 아닙니다. 전투 배치 #157은 대안이 더 좋다고 입증하지 못해 기존 선택을 유지합니다.
