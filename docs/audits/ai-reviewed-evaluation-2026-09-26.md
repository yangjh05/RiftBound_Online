# 실전 전술 보완의 평가 연결과 승률 정체 조사

## 변경 범위

- 사용자 요청: 실전에 배포한 전술 보완을 평가에도 적용하고 낮은 승률의 원인을 분석합니다.
- 신경망 승급 평가에서 후보와 상대 모두 같은 공개정보 전술 검토를 거칩니다. 동일한 48개 미리 계산 / 4개 후보 예산입니다. 웹의 추가 2초 제한은 평가에서는 쓰지 않습니다. CPU 경합이 결과를 바꾸지 않는 고정 작업량 평가이며, 웹과 시간 제한까지 동일하다는 주장은 하지 않습니다.
- 평가 요청에 보완 코드 지문과 설정을 고정하고, 경기마다 요청 식별자와 보완 식별자를 검사합니다. 보완 전 경기와 보완 후 경기를 재사용·합산할 수 없습니다. 후보만 보완하는 설정은 거부합니다.
- 양쪽 좌석별 보완 횟수, 이유, 계산 수, 예산 소진 및 오류를 저장합니다. 보완 오류는 유효한 승패로 처리하지 않습니다.
- 기존 자가대전, PPO, 학습 목표, 저장 데이터는 변경하지 않습니다. 새 신경망을 학습했다고 표시하지 않습니다.
- 실행 중이던 코드를 덮어쓰지 않고 `.tmp-ai-reviewed-evaluation-20260926/runtime`에 검증된 이전 실행본을 복사한 뒤 필요한 파일만 갱신했습니다. 원본 runtime과 학습 run을 보존합니다.

## 확인된 병목

1. 실전 Worker의 전술 보완이 이전 평가에는 없었습니다. 이번 평가 연결로 경로 차이를 줄였습니다.
2. 실전 로그 교정 9·41·73회차가 동일한 두 경기의 동일한 32개 정보 상태를 선택했습니다. `freezeSources()`가 정렬 후 앞부분을 잘라 고정된 장면을 반복합니다. 전술 모방 학습의 순환 창과는 별도 경로입니다.
3. 완료된 9·41회차 모두 행동 교정 0개, Q 제안 0개입니다. 각 1,024개의 짝지은 모의 결과 중 동률은 920개와 932개입니다. 제안 우세/기존 우세는 각각 47/57, 41/51입니다. 따라서 단순히 승급 기준만 낮추면 개선된다는 근거는 없습니다. 국소 자원 절약과 최종 승패 차이는 구분해야 합니다.
4. 최신 1279세대의 shadow Q 검증은 64개 독립 경기, 2,048쌍에서 오차 0.37082입니다. 항상 이득 차이를 0으로 예측하는 기준의 오차 0.35889보다 약 3.3% 큽니다. 이는 고정 휴리스틱 후속 플레이에 대한 진단이며 전체 Q나 실전 승률의 직접 측정은 아닙니다. 이 shadow Q는 직접 행동 교정 권한이 없습니다.
5. 전술 모방 refresh는 정답 선택률이 아니라 모방 손실 개선으로 채택됩니다. 33회차는 정답 선택률 -1.25%p, 41회차는 -0.98%p인데도 채택됐습니다. 확률 손실 개선과 실제 선택 개선이 다를 수 있습니다.
6. PPO는 매번 새 28개 학습 경기로 4 epoch 업데이트하고, 현재 학습기를 기준으로만 약하게 고정합니다. 승급 실패는 운영 챔피언을 보호하지만 학습기를 되돌리지는 않습니다. 학습 회차가 곧 개선 횟수는 아닙니다.
7. 최근 12회차의 384개 수집 경기 중 기준 목록 탐색 모드가 192개, 소폭 변형 96개, 큰 변형 96개입니다. 여러 덱과 덱 변형을 배우는 일반화 작업이 섞여 있어 고정 6개 평가 목록에 대한 즉각적인 승률 최적화와 목표가 다릅니다. 이것만으로 패배 원인이라고 단정하지 않습니다.
8. 제출 경기에서 분리된 실전 holdout audit는 현재 0개입니다. 실제 교정의 일반화를 검증하는 자료가 부족합니다.

## 해석

평가 연결은 보완의 실제 개입을 측정하게 만드는 변경입니다. 자체로 신경망의 학습 효과나 승급을 보장하지 않습니다. 과거 결과를 바꾸거나 평가 게임으로 학습하지 않습니다. 앞으로의 학습 보완은 반복 교정 표본 순환, 국소 손익과 승패 목표 분리, 덱별 선택 회귀 검사, shadow Q의 별도 검증 순서로 검토해야 합니다. 이번 전환에서는 원인 분리를 위해 학습 규칙을 동시에 바꾸지 않습니다.
