## 반영 내용

- 반복 대상 선언의 현재 선택 개수와 선택한 유닛 정보를 상태 입력에 포함합니다. 행동 입력에는 해당 대상에 배정한 피해, 추가로 유효한 피해, 제거 가능 여부를 추가했습니다. 기존 464개 입력의 위치를 유지하고 16개를 뒤에 추가합니다. 기존 가중치는 보존하고 추가 입력의 가중치만 0으로 시작합니다.
- 고정 단일 유닛 피해의 판단에 실제 엔진 `applyDamage`를 복제 상태에서 사용합니다. 전장 추가 피해, 피해 방지, 피해 배율 처리 순서를 공유합니다. 사망 유발 효과나 상대 반응까지 해결했다는 의미는 아닙니다.
- 상대 덱 추정의 반응 후보를 대상별 입력에 연결했습니다. 위력 증가로 살아남는 경우와 손으로 돌아가 전장을 비우는 경우를 구분합니다. 약화 주문을 고정 피해에 대한 방어로 계산하지 않습니다. 지원하지 않는 효과는 불확실성 입력으로 남기며 반응 불가능으로 단정하지 않습니다. 확률은 덱 후보 목록에 의존한 추정치입니다.
- 직접 룬으로 지불하는 결과와 최대 8개 자원 능력을 사용하는 결과를 비교합니다. 제한이 맞고 실제 지불에 사용되는 자원인지 엔진으로 확인하며, 능력 사용 후 실제 자원 식별자로 다시 계획합니다. 전설을 사용해서 룬 재활용을 줄일 수 있는 경우를 비교에서 배제하던 빠른 반환을 제거했습니다.
- 상대가 다음 유지 점수로 승리할 수 있는 상황의 전술 예시 생성은 주문 처리 후 이동·전투와 턴 종료까지 비교합니다. 탐색은 후보당 최대 160개 상태, 후속 이동 한 단계로 제한합니다. 상대의 선택 가능한 반응은 가정하지 않고, 강제 전투 선택도 합법적 선택지가 하나일 때만 확정합니다. 탐색 실패를 필승·필패 증거로 사용하지 않습니다.
- 이미 필요한 피해를 배정한 뒤 추가 대상을 고르는 선택도 별도 전술 예시로 학습합니다. 상대 반응을 무시한 예시는 기본 선호를 가르치는 자료이며 승률 라벨이나 강제 행동 금지 규칙이 아닙니다.
- AI의 주사위 승리 후 선후공 선택에도 로컬 사이드보딩 화면 전환을 적용합니다. 사이드보딩 중에는 AI 턴 작업을 예약하지 않습니다.
