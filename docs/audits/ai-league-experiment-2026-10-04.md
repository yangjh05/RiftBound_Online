# 챔피언 상대 학습 비교 실험

현재 학습 후보끼리의 자가대전으로 얻은 개선이 챔피언 상대 승률로 이어지지 않는 문제를 확인하기 위한 제한된 비교 실험입니다. 1759세대의 같은 체크포인트에서 두 후보를 시작하고, 상대 모델 구성만 바꿉니다. 실험 결과로 자동 승급하거나 본학습 모델을 교체하지 않습니다.

## 상대 구성과 학습량

| 조건 | 기존 방식 비교 후보 | 상대 혼합 후보 |
| --- | --- | --- |
| 상대 | 해당 회차 시작 시 자기 자신 100% | 챔피언 1163세대 50%, 과거 챔피언 982세대 25%, 해당 회차 자기 자신 25% |
| 시작점 | 1759세대 | 동일 |
| 학습량 | 32경기씩 4회, 회당 최대 4에포크 | 동일 |
| PPO 자료 | 매 경기 학습자 한 좌석만 | 동일 |
| 교정 복습 | 검증된 훈련 141사례 | 동일 |
| 교정 보존 검사 | 별도 검증 135사례 및 기존 보존 조건 | 동일 |

과거 챔피언은 이전 본학습 실행의 `initial-champion.json.gz`에 보존된 모델입니다. 과거 챔피언이었다는 사실이 현재 환경에서도 최신 후보보다 강하다는 뜻은 아닙니다. 현재 챔피언뿐 아니라 다른 운영 방식에도 대응하도록 제한된 비율로 포함했습니다.

세트, 애니, 카이사, 비오로라 마스터 이, 오로라 마스터 이, 레오나, 빅토르의 고정 덱을 사용합니다. 경기 조건과 학습 난수는 두 후보에서 대응되며, 네 번의 수집에 걸쳐 미러 및 교차 조합을 순환합니다. 현재 본학습의 덱 변형 탐색과 별도로 덱을 고정해 상대 구성의 효과를 비교합니다.

이 실험에서는 양쪽의 독립 Q 재학습 및 새 교정 사례 수집을 모두 추가하지 않습니다. 기존 가중치와 검증된 교정 복습을 사용하고, 학습 상대만 달라졌을 때의 PPO 결과를 비교합니다. 비교 후보도 한 좌석만 학습하므로, 양 좌석을 사용하던 본학습의 경기당 전체 학습량과 직접 비교하면 안 됩니다.

## 잘못된 학습 자료 유입 방지

기존 `collectAdaptiveSelfPlay`는 자기대전에서 나온 두 좌석의 궤적에 동일한 학습자 해시를 붙이고 두 궤적을 요구했습니다. 기존 호출은 실제로 같은 모델끼리 대전했으므로 이 기록 자체가 상대 행동 오염의 증거는 아닙니다. 여기에 다른 상대 모델을 그대로 넣으면 잘못된 기록 또는 검증 실패가 생기므로 새 수집 계약을 추가했습니다.

워커는 실제로 불러온 학습자 및 상대 가중치의 행동 해시를 검사합니다. 매 경기 상대를 고정하고 학습 좌석을 교대합니다. 저장 시 상대 행동의 해시를 학습자의 해시로 덮어쓰지 않습니다. 상대 좌석 궤적, 바뀐 상대, 잘못된 입력 차원, 비정상 종료 경기는 학습에 들어가지 못합니다. 재개 시 저장된 경기의 좌석과 가중치 계보를 다시 검사합니다.

가중치가 0인 상대가 난수 0에서 선택될 수 있던 경계도 수정했습니다. 이 변경은 별도 실험 실행 코드에 반영했으며, 진행 중인 본학습과 승급평가의 고정 실행 코드는 그대로 보존했습니다.

교정 사례의 정답 정의와 검증 데이터를 이용한 기울기 계산 금지 조건은 유지합니다. 현재 사용 중인 복습, 에포크 보존 검사, 거부 시 가중치와 Adam 및 난수 상태 복구를 실험 양쪽에 동일하게 적용합니다.

## 평가와 해석

네 차례 학습 후 초기 모델, 자기대전 비교 후보, 상대 혼합 후보를 각각 고정한 1163세대와 평가합니다. 단일 덱 목록 7개와 두 덱 목록 21개에 목록당 8경기를 배정하므로 모델당 224경기, 총 672경기입니다. 같은 평가 난수와 덱, 좌석, 선후공 조건을 사용합니다. 평가 난수는 실험 훈련과 분리하며 평가 결과는 학습에 되먹이지 않습니다.

후속 검증에서 두 덱 목록의 시드가 짝수이면 실제 행렬 선택이 교차가 아닌 각 덱의 미러가 되는 제한을 확인했습니다. 이 실행은 이미 고정되어 있으므로 조건과 기록을 바꾸지 않습니다. 결과는 실제 경기의 덱 구성을 기준으로 해석해야 하며, 교차 21조합을 모두 검증했다고 주장할 수 없습니다. 새 챔피언 출발 비교에서는 교차 시드와 양방향 배정을 바로잡았습니다. [후속 변경 근거](ai-learning-anchor-2026-10-04.md)

현재 본학습 승급평가의 고정된 실행 코드와 양측에 같은 공개정보 검토를 사용합니다. 결과는 전체 및 덱별·미러·교차 승률, 초기 모델 및 비교 후보 대비 같은 조건에서 더 이긴 경기와 더 진 경기로 저장합니다.

224경기는 제한된 선별 실험입니다. 소폭의 승률 차이를 실력 향상 확정으로 해석하지 않습니다. 개선이 보이면 기존 승급 기준으로 후속 검증해야 하며, 개선이 없으면 그대로 본학습에 적용하지 않습니다. 최근 승급 실패가 이 구조 때문이었다는 인과관계도 아직 확정하지 않았습니다.

## 실행과 보존

- 실험 자료: `data/ai/league-policy-experiment-20261004`
- 고정 실행 코드와 실행 스크립트: `.tmp-ai-league-20261004`
- 진행 상태: 실험 폴더의 `status.json`, `events.jsonl`, `state.json.gz`
- 최종 비교: 실험 폴더의 `result.json`
- 본학습과 빅토르의 기존 프로세스 및 진행 중 승급평가는 계속 유지합니다.
- 최대 16개 한도에서 수집·학습 실험에 3개 슬롯을 예약합니다. 컨트롤러 1개와 수집 워커 최대 2개이며, 기존 작업이 안전하게 슬롯을 반환한 것을 확인한 후 시작합니다. 양쪽 학습 완료 후 평가만 재개할 때에는 1개 슬롯만 예약합니다. 우선순위는 기존 Normal 설정을 따릅니다.
- 자료와 체크포인트는 별도 저장합니다. 실험이 끝나면 자신이 추가한 슬롯만 반환합니다.

코드 검증은 원본 경로의 수집·워커·실험 관련 18개 테스트와, 고정 실행 경로의 실험·교정 보존·Adam 복구 11개 테스트가 통과했습니다. 중복 테스트가 있으므로 두 수를 독립 테스트 수로 합산하지 않습니다. 763개 실행 파일 지문과 3개 실제 체크포인트의 네이티브 TensorFlow 추론, 입력 차원 6026과 행동 차원 521, 교정 훈련·검증 분리를 확인했습니다. 승률 개선은 실제 비교가 끝난 뒤 판단합니다.

2026년 10월 4일 오전 5시 48분 실제 저장 자료 검증에서 첫 32경기가 완료됐고, 상대는 1163세대 16경기, 982세대 8경기, 1759세대 8경기였습니다. 모든 경기에서 학습자 한 좌석의 궤적만 저장됐으며 두 좌석이 모두 사용됐습니다. 기존 승급평가 99번은 585경기로 계속 진행 중이었고 대시보드는 HTTP 200이었습니다. 첫 회차는 첫 에포크가 수치 검사에는 통과했지만 교정 보존 조건을 충족하지 못해 조기 종료됐고, 실제 가중치는 변경되지 않았습니다. 현재 같은 조건의 자기대전 비교 후보를 수집 중입니다. 혼합 상대 학습이 보존 검사 거부를 줄이거나 실제 승률을 높일지는 미확정입니다.

## 평가 호출 오류 수정과 최근 결과

10월 4일 오전 6시 23분 두 후보의 4회차 학습이 모두 끝난 후 평가가 중단됐습니다. 새 실험 실행 코드가 `evaluateNeuralModels(candidate, opponent, decks, options)`에 덱 배열을 세 번째 인자로 전달하지 않고 옵션 객체 안에 넣은 오류였습니다. 테스트가 수집·기록·교정 보존을 검사했지만 실제 평가 호출 경계는 확인하지 못했습니다. 이 오류는 본학습이나 본학습 승급평가에는 적용되지 않았습니다.

오후에 호출 경계를 수정하고, 실제 공용 평가 함수를 사용해 미러전과 교차전의 8경기 난수·좌석·선후공·검토 설정 및 저장 경기 재사용을 검사하는 회귀 테스트를 추가했습니다. 잘못된 덱 전달을 조기에 거부하며, 양쪽 학습 완료 상태에서만 운영상 예약을 3개에서 1개로 줄일 수 있게 했습니다. 원본 및 고정 실행 경로에서 각각 11개 관련 테스트가 통과했습니다. 실험의 구성, 상대, 학습 난수, 평가 난수, 교정 기준은 변경하지 않았습니다.

기존 실험 자료 287개 압축 아카이브의 지문과 오류 로그를 보존한 뒤 실행 코드만 수정했습니다. 양쪽 후보는 각각 128경기를 완료했고, 혼합 후보는 3회차에, 자기대전 후보는 1회차에만 1에포크가 허용됐습니다. 둘 다 1760세대이지만 행동 해시는 서로 다릅니다. 세대 번호나 학습 시도 횟수는 실력 향상의 증거가 아닙니다.

같은 날 오후 5시 30분 본학습 승급평가는 다음과 같았습니다. 상대는 모두 1163세대입니다.

| 1763 | 672 | 42.56% | 열세로 완료 |

완료한 1777세대의 같은 덱 미러전은 71승 121패로 36.98%였습니다. 따라서 덱 구성 간 강약 차이만으로 낮은 승률을 설명할 수 없습니다. 다만 서로 다른 난수를 사용한 후보 간 몇 퍼센트 차이 자체를 확정적인 연속 퇴행으로 해석하지는 않습니다. 최근 두 완료 후보가 챔피언보다 열세라는 근거는 평가 결과에 있습니다.

본학습 433회차부터 완료된 최근 45회차에서는 176개 에포크 중 174개가 허용됐고, 45회차 모두 가중치를 갱신했습니다. 허용 유형은 전체 정책 86개, 플레이 행동 행만 변경 75개, 기존 복구 방식 13개였습니다. 현재 본학습의 낮은 승률을 단순히 업데이트 거부 탓으로 돌릴 수 없습니다. 국소 교정 보존 검사를 통과하는 것과 전체 경기에서 강해지는 것은 다릅니다. 자기 자신과 대전하며 생기는 편향이 원인인지는 혼합 상대 실험의 별도 평가가 필요하며, 현재 확정된 인과관계는 아닙니다.

오후 5시 39분 재개 검증에서 별도 평가의 첫 실제 완료 경기 저장을 확인했습니다. 기존 287개 압축 아카이브와 본학습 실행 코드의 지문은 일치했고, 대시보드 HTTP 200 및 본학습 평가 102번의 488경기 진행을 확인했습니다. 당시 1792세대는 203승 285패, 41.60%였습니다. 별도 평가 프로세스는 Normal 우선순위이며 1개 슬롯을 예약했고, 검사 시 전체 학습 관련 프로세스는 14개였습니다. 최종 672경기 비교는 아직 완료되지 않았습니다.
