# 공개정보 기반 상대 대응 학습 보완

사용자가 승인한 상대 패 추정과 행동별 대응 손익의 연결을 학습용 교정 경로에 적용했습니다. 기존 run의 86회차/1293세대 저장 후 재개했으며, 첫 적용은 87회차/1294세대 준비입니다. 진행 중인 평가 73(1279 대 1163)의 요청과 122경기는 변경하지 않았습니다.

## 확인한 원인

- 비활성화된 신경망 belief 손실은 상대 손패가 아니라 덱 전체 카드 구성의 복원을 목표로 했습니다. 손패와 덱의 카드를 바꿔도 정답은 같으므로 단순 재활성화는 현재 대응 예측의 해결책이 아닙니다.
- 기존 대응 교사의 기본 덱 목록에 새 애니와 비오로라 마이가 정확히 등록되어 있지 않았습니다. 후보가 하나이면 목록이 불완전해도 posterior 1이 될 수 있습니다.
- 기존 교사는 행동 전의 타이밍과 비용으로 반응 후보를 골랐고, 기존 반응 탐색은 chain이 비어 있는 전투에서 카드를 사용할 기회를 만들지 않았습니다.
- 상대 반응 후 자신의 자발적 재대응은 pass로 처리했습니다. 공개된 상대 발동 능력도 손패 카드 가설과 함께 비교되지 않았습니다.

## 적용한 변경

- 새 `scripts/response-policy-learning.mjs`는 공통 덱 후보 목록으로 공개 패 추정을 수행합니다. 현재 기준 덱과 전체 공개 탐색 후보를 사용하며 실제 상대의 deckId나 숨겨진 패/덱 순서로 목록을 선택하지 않습니다. 87회차 첫 목록은 중복 구성 제거 후 30개입니다. 매 교정 회차에 전체 후보를 다시 반영하고, 해당 회차의 목록 해시를 고정합니다.
- 후보 내 확률을 실제 목록의 확실성으로 표시하지 않습니다. 공개된 카드가 후보들로 설명되지 않으면 낮은 신뢰도로 처리합니다. 목록 밖 카드가 없다고 보증하지 않습니다.
- Reaction/Action 카드를 후보에 남기고, 후보 행동 실행 후 실제 엔진의 합법 행동과 지불로 대응 가능 여부를 확인합니다. 이동 후 열린 전투의 빈 체인도 검사합니다.
- 상대는 카드 사용과 pass 중 공개 손익이 더 좋은 쪽을 선택합니다. 카드·룬 소모도 가치에 포함되므로 보유했다고 무조건 사용한 것으로 간주하지 않습니다.
- 상대의 공개 발동 능력도 비교합니다. 상대의 손패가 0장이어도 사용할 수 있는 보드 대응은 사라지지 않습니다.
- 상대 대응 후 자신의 재대응 후보 최대 2개와 pass를 비교합니다. 상대 한 번, 자신 한 번의 자발적 대응을 허용하는 제한된 탐색이며 무한 체인을 해결했다고 주장하지 않습니다.
- 경기당 최대 8개 장면, 장면당 최대 4개 행동·3개 패 가설, 가설당 192개 검색 상태로 연산을 제한합니다. 탐색이 끝나지 않은 경우 unknown으로 남겨 무해한 대응으로 바꾸지 않습니다.
- 새 교정 표본에 보유 확률, 행동 후 사용 가능 여부, 상대의 사용 선택, 자신의 재대응 사용, 후보 덱 해시를 기록합니다. 실제 행동 모방 학습에 전달하며 승률 정답이나 Q 확정 증거로 사용하지 않습니다.
- 86회차 이후 별도 불변 프로토콜 `prospective-public-response-learning-v1`을 적용합니다. 87회차에 즉시 교정하고 이후 기존 8회차 교정 일정을 따릅니다. 저장된 이전 교정 경기와 결과는 재해석하지 않습니다.

## 범위와 한계

이번 변경은 교정 자료를 생성하는 학습 경로에 적용됩니다. PPO의 기존 상태 입력 형식과 엔진, 이미 진행 중인 승급 평가의 보완 검토기는 그대로입니다. 이미 배포된 모델이 즉시 새 추정 모듈을 호출하는 변경은 아닙니다. 새 교정이 선택률 검증을 통과해야 가중치에 채택되고, 실제 실력 향상은 별도 대전으로 확인해야 합니다.

반응 카드별 보유 확률은 서로 겹치는 주변 확률입니다. 이를 이용한 기대 손익은 `approximate-hand-marginals-with-opponent-choice`라는 근사값으로 명시하고 실제 승률이라고 부르지 않습니다. 상대의 카드 사용 여부는 제한된 공개 손익 탐색의 선택이며 사람의 사용 확률을 학습한 값은 아닙니다. 알려지지 않은 새 덱/비공개 숨김 카드의 정확한 정체를 확정하지 않습니다.

신경망의 전체 덱 복원 손실을 다시 켜거나 새로운 손패 예측 머리를 도입하지 않았습니다. 먼저 기존 공개정보 기반 추정과 실제 대응 계산의 누락을 고쳐 행동 교정 자료로 연결했습니다. 전체·덱별 모방 선택률 퇴행 방지 조건도 유지합니다.
