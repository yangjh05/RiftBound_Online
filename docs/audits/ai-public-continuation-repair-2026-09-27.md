## 변경

- 새 `public-continuation.mjs`는 상대의 공개 강제 피해 배정을 모두 비교하고 상대에게 유리한 결과를 사용합니다. 상대 선택 일부를 계산하지 못하면 미해결로 남깁니다. 자기 이동 목적지 선택도 엔진의 실제 후속 처리까지 계산합니다.
- 덱 순서와 상대 비공개 카드는 가립니다. 상대의 덱/무덤 재활용 선택은 임의로 결정하지 않고 같은 선택·남은 continuation 경계에서 비교합니다. 보드 상태는 별도 평가합니다.
- `runtime-tactical-review.mjs` v3는 미완성 검색으로 모델 행동을 변경하지 않습니다. 후속 검색이 불완전하면 얕은 턴 종료 점수만으로 전개를 포기시키지 않습니다. 동일 보드·자원 보존 또는 완료된 종국 비교가 확인된 경우만 별도 취급합니다.
- 룬 성장·드로우·예측 등의 미래 전개 행동은 당장 비용을 아낄 수 있다는 이유만으로 턴 종료로 바꾸지 않습니다. 이 조치는 장기 최적 가치를 완전히 계산했다는 뜻이 아닙니다.
- 멀리건은 자기 덱의 알려진 구성에서 1~2장 교체의 기대 초기 전개 품질을 계산합니다. 초반 유닛/성장 수단, 무거운 패, 중복을 고려하고 충분한 차이가 있을 때 부드러운 정책 학습 예제로 기록합니다. 덱 순서나 상대 비공개 카드로 정답을 만들지 않습니다.
- 새 시범 학습도 같은 안전한 검토 경로를 사용합니다. 기존 PPO 확률/상태/행동 목록/보상, 과거 정답, Q의 승률 표적은 바꾸지 않습니다. 새 교정은 검증 손실과 기존 전체·덱별 퇴행 검사를 통과한 가중치만 채택합니다.
- 새 혼합 평가의 덱별 퇴행 검사는 후보와 상대 모델이 같은 덱을 맡았을 때의 성적을 비교합니다. `relativeScore = (1 + candidateScore - opponentScore) / 2`; 기존 0.4 하한을 여기에 적용합니다. 절대 승률은 계속 보고합니다. 전체 증거 기준, 상대 조합·좌석·선공·미러/비미러 검사, 경기 예산은 유지합니다. 과거 요청에는 종전 절대 승률 기준을 그대로 사용합니다.
