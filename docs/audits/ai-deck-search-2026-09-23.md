# 오리진 합법 덱 탐색 학습

사용자 요청에 따라 기존 다섯 전설을 유지하고 **Origins·Proving Grounds 카드만** 사용합니다. 다른 세트 카드와 현재 Standard 금지카드는 전 구역에서 제외합니다. 2026-09-18 금지 목록은 [공식 Rules Hub](https://playriftbound.com/en-us/rules-hub/)와 확인했습니다. 학습 덱에는 기본 제공 덱의 금지 예외가 없습니다.

## 탐색 방법

- 시험 덱 배정의 50%는 합법화한 기준 덱, 25%는 메인 1~3장 변경, 25%는 6~12장 변경입니다. 변형 배정의 각각 10%는 룬 또는 전장 변경에 사용합니다. 상대는 전설별로 순환하는 기준 덱입니다. 따라서 전체 좌석에서 기준 덱이 차지하는 비율은 시험 덱 배정의 50%보다 높습니다.
- 초기에 기존 덱의 구조를 보존하고, 새 카드는 전체 합법 후보에서도 뽑아 기존 점수나 카드 정렬 순서에 갇히지 않게 합니다. 전설당 변형 후보는 최대 6개입니다. 기존 후보를 충분히 사용한 뒤 성적을 참고해 부모를 선택하고 새 후보를 만듭니다.
- 40장 메인, 12장 룬, 전장 3종, 도메인, 챔피언, 같은 이름의 합산 매수, 고유 카드, 시그니처 합계, 사이드보드 제한은 기존 공용 덱 검사기를 사용합니다. 생성 시점과 워커 실행 시점에 검사합니다.
- 한 회차의 정책·덱 구성·경기별 배정을 수집 전에 저장합니다. 8경기 단위로 좌석과 선후공을 바꾸며, 중단 후에도 동일한 배정과 카드 구성 해시를 검사합니다.
- 상대 전설별 성적과 그 안의 좌석·선후공 네 조건에 같은 가중치를 주고 각 상대에 12경기 분량의 중립 사전값을 사용합니다. 검증 경기 제외로 조건별 표본 수가 달라져도 유리한 조건이 점수를 독점하지 않습니다. 소수 경기의 100% 승률을 확정 우위로 취급하지 않습니다. 정확히 같은 덱끼리의 경기는 덱 우열 통계에서 제외합니다.
- 기존 독립 검증 경기의 승패는 덱 후보 선택에도 사용하지 않습니다. 덱 선택 통계는 회차 저장과 함께 갱신되어 재개 시 중복 집계하지 않습니다.
- 현재 자가대전은 단판이므로 사이드보드는 합법 상태로 보존합니다. 사이드보드 최적화 성적을 주장하지 않습니다.

## 오로라와 기준 덱

오로라에 불이익을 주는 카드별 규칙은 없습니다. 기존 마스터 이 덱은 오로라 3장과 6코스트 이상 카드 12장을 보존하고 금지 전장만 교체했습니다.

추가한 비오로라 출발점은 `keenan-xiong`을 오리진 환경에 맞춘 **미검증 초안**입니다. 원본 메인 21장, 사이드보드 3장, 전장 1장이 다른 세트이며 금지 전장 1장도 있어 원본을 그대로 사용할 수 없습니다. 가능한 한 카드 종류와 비용을 유지하는 자동 보정으로 메인 평균 비용 2.525, 6코스트 이상 카드 3장의 저비용 출발점을 만들었습니다. 합법성과 비용 분포 보존은 경쟁력을 보장하지 않습니다. 검증된 오리진 비오로라 덱을 추가할 수 있다면 탐색 효율이 더 좋아질 수 있습니다.

애니 기준 덱도 금지 메인 8장을 교체하므로 보정 후 성능은 미검증입니다. 원본 덱의 경쟁력을 새 보정 덱에 그대로 귀속하지 않습니다. 모든 보정 내역과 `seedQuality`를 기록합니다.

## 실행과 결과 해석

현재 실행은 `adaptive-policy-q-live-games-20260922`입니다. 202회차 저장 후 `deck-search-protocol.json`을 추가했으며 203회차부터 적용합니다. 체크포인트를 초기화하지 않습니다. 기존 자료와 이미 시작된 평가를 재작성하지 않습니다. 이후 새 정책 평가는 저장한 합법 기준 덱으로 두 정책을 같은 덱에서 비교합니다.

새 실행 코드는 `.tmp-ai-deck-search-20260923/runtime`, 재개 스크립트는 같은 상위 폴더의 `run-training.ps1`입니다. 엔진 지문은 `sha256:2801a7f4b0d846830c29133b19c381ad660726232e36e8caa25c845df78f6be1`로 유지됩니다.

회차별 `deck-search-report.json.gz`에는 카드 구성, 상대별 균등 가중 성적, 경기 수, 상대 전설 수와 미인증 상태를 저장합니다. 이 순위는 탐색용입니다. 학습 정책이 회차마다 바뀌고 성적이 후보 선택에 사용되므로 독립적인 최강 덱 인증이나 통계적 우위 증명이 아닙니다. 최종 덱 우위를 주장하려면 정책을 동결하고 새 시드와 다양한 상대를 사용한 별도 비교가 필요합니다.

다른 실행에서 활성화할 때는 저장 경계에서 컨트롤러를 중단한 뒤 `node scripts/enable-deck-search.mjs <실행 폴더>`를 사용합니다. 진행 중인 미완료 회차가 있으면 전환을 거부합니다.
