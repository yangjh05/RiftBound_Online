# 행동별 반응 학습과 Shadow Q 활용 경로

후속 운영 검사에서 발견한 검증 역할명 불일치와 자료 복구는 [검증 역할 복구 기록](ai-validation-role-recovery-2026-09-23.md)에 정리했습니다. 아래의 최초 실행 확인 이후 독립 검증 집계가 막혀 있었으며, 202회차 저장 경계에서 복구했습니다.

사용자 요청: 고정 덱 구성 예측의 낭비를 줄이고, 행동별 상대 대응 손익을 정책에 반영하며, Shadow Q의 학습·검증·활용을 연결합니다.

## 적용 범위

- 현재 실행 `adaptive-policy-q-live-games-20260922`의 98회차/909세대 저장 후 정상 중단했습니다.
- 같은 실행의 99회차부터 `policy-q-utility-protocol.json`을 적용합니다. 체크포인트 초기화, 예전 경기 재분류, 운영 챔피언 교체를 하지 않습니다.
- 기존 엔진, 입력 차원, 카드 사전, 행동 집합과 평가 동작은 바꾸지 않았습니다. 엔진 지문은 `sha256:2801a7f4b0d846830c29133b19c381ad660726232e36e8caa25c845df78f6be1`로 동일합니다.
- 고정 실행 코드: `.tmp-ai-policy-q-utility-20260923/runtime`. 재개 스크립트: 같은 폴더 상위의 `run-training.ps1`.
- 최대 연산 슬롯 16개와 저장된 우선순위 설정을 유지합니다. 전환 시 우선순위는 Normal입니다.

## 변경

1. 새 PPO 업데이트의 덱 구성 예측 손실 가중치를 0으로 설정했습니다. 덱 예측 출력과 기존 가중치는 호환성을 위해 보존합니다. Policy, 상황 가치, 정책 내부 행동 가치는 계속 학습합니다.
2. 전술 연습에서 실제 게임 엔진으로 비용·대상·반응 체인·현재 전투를 진행해 행동별 반응 손익을 비교합니다. 한 경기 최대 6개 장면, 장면당 최대 4개 행동과 2개 반응 가설로 제한합니다. 상대는 반응하지 않는 선택도 할 수 있습니다. 상대의 비공개 패 대신 공개 정보로 추정한 카드만 사용합니다.
3. 반응 가정 결과를 가벼운 정책 모방 학습으로 전달합니다. 실제 행동의 강제 금지나 승률 정답으로 취급하지 않습니다. 반응 후에도 이득인 행동을 허용하고, 검색이 끝나지 않은 분기를 무해한 것으로 취급하지 않습니다. 반응 보유 확률은 서로 독립인 정확한 세계 분포가 아니므로 결과를 근사 단일 반응 혼합값으로 명시합니다.
4. 수집 전 확정한 32경기 중 4경기는 두 플레이어를 모두 검증용으로 보존합니다. 해당 경기는 PPO·Q 훈련·Q 정책 교정 제안에서 제외합니다. 나머지 28경기로 PPO를 갱신합니다. 검증 인덱스는 8회차 동안 순환합니다. 이전 경기를 뒤늦게 검증용으로 바꾸지 않습니다.
5. 검증용 대안 비교는 32개의 독립 시드 쌍으로 상한을 고정합니다. 이는 한 장면의 우열을 확정하기 위한 승급 기준이 아니라, Q 예측 오차를 측정하는 표본입니다. 시드 수를 독립 경기 수로 부풀리지 않고 경기별 동일 가중치를 사용합니다.
6. 검증 경기를 우선하는 감사 큐를 추가했습니다. Q의 독립 검증이 최소 32경기 있고, 대안 차이를 항상 0으로 예측하는 기준보다 오차가 작을 때에만 Q가 재감사할 훈련 장면을 제안합니다. 이 기준은 **제안 선별 권한**이며 행동 교정·승급 인증이 아닙니다.
7. Q 제안은 기존 실전 정책 교정 경로에 연결됩니다. 선택 시점의 정확한 현재 정책으로 별도의 32개 선별 시드와 128개 확인 시드를 사용하고, 기존 다중 비교 기준·정책 변화 제한·독립 회귀·40경기 켬/끔 진단을 유지합니다. 정식 승급은 기존 챔피언 대전으로 별도 판정합니다. Q는 고정 휴리스틱 후속 플레이를 배웠으므로 Q 점수만으로 실제 행동을 강제하지 않습니다.

## 검증 및 한계

관련 회귀 검사 44개 통과. 실제 엔진의 반응 처리와 비공개 패 교체 불변성, 수집 전 경기 단위 분리, 예전 자료 역할 보존, 덱 예측 손실을 끈 실제 TensorFlow 정책 업데이트, 실제 32시드 종료 대국을 사용한 Q 검증, 동결한 현재 정책의 독립 재감사·정책 교정·워커 재개를 확인했습니다.

검증 작업이 기존 장기 감사 작업 뒤에 밀리지 않도록 감사 요청 슬롯 2개를 검증에 예약하고, 워커는 저장된 4시드 단위 작업 경계에서 검증을 우선 선택합니다. 검증 작업이 없을 때에는 훈련 감사 계산을 계속합니다. 기존 시드, 경기, 완료한 계산은 보존합니다. 이 배정 변경까지 추가 검사 14개를 통과했으며, 앞선 36개와 겹치는 6개를 제외한 총합이 44개입니다.

원본 설정, 출발 모델, 챔피언, 동결 평가 요청 파일의 해시를 보존했습니다. 변경은 학습용 스크립트에 한정되므로 게임 카드/엔진 변경용 `check:no-ai` 대신 해당 AI 회귀 검사를 실행했습니다.

Q를 사용한 승률 향상은 아직 입증되지 않았습니다. 검증 자료를 새로 모아야 하며, 통과하지 않으면 Q가 직접 정책을 수정하지 않습니다. 고정 후속 정책으로 배운 Q의 한계를 현재 정책 재감사로 보완합니다. 전술 연습의 근사 손익과 모방 적합도 개선도 실제 승급을 보장하지 않습니다.

실행 증거와 후속 진행은 `.tmp-ai-policy-q-utility-20260923/transition.json`, `verification-tests.log`, `verification.json`에 기록합니다.
