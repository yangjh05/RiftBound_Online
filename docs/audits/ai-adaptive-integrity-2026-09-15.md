# Adaptive Policy–Q 학습 경로 엄격 검증

2026-09-15. 범위는 현재 실행 중인 AI 학습·자료 재사용·저장 상태 정밀 계산·대전 평가·승격·중단 후 재개입니다.
카드 효과나 게임 엔진을 변경하지 않았으며, 저장 자료의 엔진 fingerprint도 유지했습니다.
아래 결과는 이 경로에 대한 코드 검토, 회귀 테스트와 실제 자료 검증입니다. 저장소 전체의 모든 오류가 없다는 증명은 아닙니다.

## 확인한 문제와 수정

| 문제 | 영향과 수정 |
| --- | --- |
| 기존 워커 종료 후 분할 재생성 | 실행 중 이미 확정한 분할 대신 더 오래된 분할을 다시 적용했습니다. 이전 Training 6경기가 Validation으로, 이전 Validation 3경기가 Training으로 이동했습니다. 모든 확정 역할과 고정 Anchor를 보존하도록 수정했습니다. 새 경기만 배정합니다. |
| 오래된 후보가 평가 대기열을 점유 | 진행 중인 후보 뒤에 오래된 후보가 남아 최신 학습의 평가가 지연됐습니다. 진행 중인 평가는 유지하고 대기 후보만 최신 후보로 교체합니다. 시작하지 않은 기존 요청 2번은 보존하되 실행 대기에서 제외합니다. |
| 평가 결과와 승격 검증 부족 | 요청·통계 조건·게임별 seed/덱/좌석/선공/무작위 흐름·완료 여부를 검사하고, 저장 경기에서 판정을 재계산합니다. 결과의 요약 hash와 재계산 결과가 맞아야 사용합니다. |
| 중단 후 평가 또는 승격 중복 | 평가 잠금으로 살아 있는 평가를 인계하고, 예약을 먼저 저장해 동일 예약을 복구합니다. 이미 같은 후보가 배포됐으면 승격 쓰기를 반복하지 않습니다. 외부에서 다른 챔피언으로 바뀌었으면 중단합니다. |
| 정밀 계산 라벨의 원래 경기 식별 부족 | player/step 외에 원래 gameId도 일치해야 라벨을 부착합니다. 재사용하는 완료 증거의 원본·위치·일정·reference를 검증합니다. 종료됐지만 쓸 수 없는 감사는 유효한 Q 학습 자료 수에 포함하지 않습니다. |
| 비정상 숫자 저장 | NaN/Infinity가 JSON null로 저장되고 재로드 시 정상 숫자처럼 해석될 수 있는 경로를 차단했습니다. 저장 전·로드 전 tensor 크기와 모든 가중치를 검사합니다. 평균에서 제외돼 감춰질 수 있는 비정상 PPO 배치는 원래 지표로 검사해 롤백하고, 비정상 Q 지표도 후보 확정 전에 거부합니다. |
| 중단·자원 배정·불필요한 읽기 | 감사 풀은 진행 중인 seed 조각을 저장한 뒤 멈추고 대기 조각은 재개 때 처리합니다. 완료한 기존 실행의 PID가 재사용돼도 슬롯을 계속 예약하지 않습니다. 이미 완료한 감사 계획을 반복해서 디스크에서 읽지 않습니다. |
| Windows 진행률 파일 잠금 | 실제 평가 재개 시험에서 `progress.json` 교체의 EPERM을 재현했습니다. 기존 공용 재시도 함수를 사용하고, 재사용한 경기마다 진행률을 다시 쓰지 않도록 수정했습니다. |

## 기존 자료에 대한 조치

- 오류 이전의 확정 분할을 복원했습니다. 늦게 도착했고 이미 학습에 사용한 새 경기 2개도 Training으로 고정했습니다. 결과는 **학습 1,398경기 / 내부 검증 349경기**입니다.
- 1~66회차 Q 학습 계획을 전부 대조했습니다. 원래 검증 자료 및 복원 후 검증 자료의 학습 유입은 **0건**입니다.
- 64~66회차의 내장 Shadow 점수는 재배정된 목록으로 계산돼 무효화했습니다. 복원한 검증 349경기로 다시 계산하여 각 회차의 `shadow-revalidated.json.gz`에 저장했습니다. 기존 후보 파일은 변경하지 않았습니다.
- 자기대전 **2,112경기**의 자연 종료·승자·양측 궤적·회차/경기 ID·수집 정책 출처를 검사했습니다. 후보 **66개**의 가중치 크기와 유한성 검사도 통과했습니다.
- 평가 1번의 저장된 **450경기**는 동결한 원래 조건과 모두 일치했습니다. 원래 hash 없는 구버전 결과는 개별 파일 hash를 기록한 명시적 인계 자료로 한정해 재사용합니다. 신규 결과에는 요청 hash가 들어갑니다.
- 입력 모델, 후보 1·2·66, 평가 요청 1·2, 불변 설정의 파일 hash가 유지됨을 확인했습니다. 경기 원본은 재작성하지 않았습니다.
- 기존 1,962개 감사 자료는 보관합니다. 그중 1,747개가 기존 Training 내부 분할 대상이고 나머지 215개는 Calibration 자료입니다. 자료를 전부 PPO에 투입하는 방식으로 바꾸지 않았습니다.

## 검증

서로 다른 관련 회귀 테스트 **56개 통과**:

- 분할 보존, 학습 자료 격리, 게임 출처와 숫자 검사, 평가 계약·예약·승격·잠금·fingerprint: 17개
- 실제 분리 감사, seed 조각 재사용, 워커 증감, 자기대전 전달 옵션 및 Shadow 정밀도 회귀: 24개
- 감사 중단 시 진행 중 조각만 저장하고 대기 조각을 유지하는 추가 시험: 1개
- PPO 지표·롤백·Adam/RNG 재개, Q head 분리, 스트리밍 감사 및 기존 잠금 회귀: 8개
- Windows 파일 교체·쓰기 재시도 회귀: 4개
- 원래 PPO 배치의 비정상 지표 검출 및 실제 PPO의 가중치 롤백: 2개

추가로 실제 저장 경기 320개와 실제 모델을 별도 시험 디렉터리에서 평가기로 다시 읽었습니다.
320개를 재대전하거나 파일을 다시 쓰지 않고 재개했으며, 저장 결과로 판정을 재계산하는 검증도 통과했습니다.
이 시험의 축소된 평가 판정은 실제 실행의 승격 판단에 사용하지 않습니다.

변경한 실행 모듈의 구문 검사와 추적 중인 수정 파일의 공백 검사도 통과했습니다.
카드/엔진 변경은 없으므로 `check:no-ai`는 실행하지 않았고, 전체 저장소 테스트를 통과했다고 주장하지 않습니다.

## 적용과 기록

교체 준비 중 진단 연결을 끝내기 위해 사용한 일회성 코드의 동적 import 오류로 이전 실행이 예상보다 일찍 종료됐습니다.
저장된 후보·원본·완료한 평가 경기·감사 조각은 유지했습니다. 저장되지 않은 마지막 계산은 재개하면서 다시 수행합니다.
이 오류를 정상적인 무중단 인계로 기록하지 않습니다.

수정된 컨트롤러는 04:46 KST에 시작했습니다. 67회차 자기대전과 평가 1번의 451번째 경기부터 재개했습니다.
67회차는 새 32경기 수집, PPO, 기존 96경기와 새 감사 7경기의 Q 학습,
복원한 검증 목록의 점검을 마치고 후보 저장까지 완료했습니다. 새 후보의 가중치와
원래 PPO 배치 지표도 유한하며, 검증 목록 hash가 복원한 분할과 일치했습니다.
추가된 배치 지표 검사는 67회차 저장 후 감사 조각을 정상적으로 마무리한 다음
다음 컨트롤러에 적용했습니다. 평가 PID 29064는 그대로 인계해 재대전 없이 계속합니다.
검증한 자기대전은 합계 **2,144경기**, 후보 가중치는 **67개**입니다.
High 우선순위와 최대 16개 계산 슬롯(자기대전 8, 정밀 감사 6, 평가 1, 학습 1)을 유지합니다.
완료 경기 수나 내부 Shadow 점수만으로 더 나은 실전 AI라고 판단하지 않으며, 원래 동결 평가 기준을 유지합니다.

실제 검증 자료는 `.tmp-ai-strict-audit-20260915/`의 `split-repair-proof.json`, `history-proof.json`,
`shadow-recheck-proof.json`, `evaluation-adoption-proof.json`, `evaluation-resume-proof.json`,
`live-repair-proof.json`, `runtime-verification.json`과 테스트 로그에 있습니다.
당시 상태와 교체 전 소스도 같은 디렉터리에 보관했습니다.
