## 평가 기준의 별도 문제

`sequential-match-statistics.mjs`의 mixed safety는 각 덱의 후보 절대 승률이 `regressionFloor`(40%) 이상인지도 검사한다. 동일 덱에서 챔피언 역시 40% 미만이면, 이 조건은 챔피언 대비 퇴행과 덱/공통 정책의 절대 약세를 구분하지 못한다. 후보 승률을 낮추는 원인은 아니지만 승급 해석에는 영향을 준다. 기존 고정 평가를 소급해 변경하거나 통과 처리하지 않았다.

## 수정 방향

1. 상대의 공개 강제 피해 배정은 가능한 배정을 비교해 상대에게 유리한 결과로 평가한다. 미계산 상태를 패스나 안전한 행동으로 취급하지 않는다.
2. 완성되지 않은 분기와 턴 종료를 비교해 모델 결정을 강제로 바꾸지 않는다. 동일 결과·최소 소모가 검증된 경우와 근사적인 전략 판단을 분리한다.
3. 룬 성장·드로우·준비의 미래 전개 가치, 합동 공격, 멀리건을 덱별 실제 상황으로 검증한다. 특정 카드 이름의 예외로 고치지 않는다.
4. 고정 평가와 분리한 대조 실험으로 수정 전후를 비교한다. 승급 판단은 같은 상대 분포에서 기존 챔피언 대비 성능과 덱별 절대 성능을 구분한다.
