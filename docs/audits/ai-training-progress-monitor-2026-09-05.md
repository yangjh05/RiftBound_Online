# 수집 작업의 경과 시간 제한 제거와 진행 관측

## 동작 변경

- 단판 45분·매치 가능 풀 135분의 기본 경과 시간 제한을 제거했습니다. 별도로 양수 `maximumTaskDurationMs`를 지정한 호출만 제한을 사용합니다. 기본값과 0은 제한 없음입니다.
- 프로파일링이 꺼져 있어도 경기 복사, 합법 행동 검사, 행동 적용, 신경망 추론, 탐색 계산 횟수를 기록합니다. 행동 적용과 탐색 횟수에는 시뮬레이션이 포함됩니다. 실제 대전의 행동 수나 전략적 진전을 직접 나타내는 지표는 아닙니다.
- 계산 경계에서 최대 5초 간격으로 작은 진행 파일을 원자적으로 교체합니다. 일반 타이머나 IPC 콜백과 달리 작업자의 동기식 탐색이 끝나기를 기다리지 않습니다. 관측 파일은 해당 풀의 임시 디렉터리에 있으며 풀 종료 시 함께 정리됩니다.
- 부모 프로세스가 각 시도의 고유 토큰과 증가하는 계산 횟수를 확인합니다. 이전 시도의 파일, 같은 기록의 재조회, 시간 정보만 바뀐 기록은 새 진행으로 인정하지 않습니다.
- 5분 동안 새 기록이 없으면 `no-recent-progress` 경고를 남기고 작업을 계속합니다. 긴 네이티브 계산이나 관측 실패도 가능하므로 기록 부재만으로 강제 종료하거나 재시도하지 않습니다. 새 계산 기록을 받으면 경고 상태를 해제합니다.
- 실제 프로세스 종료·오류에 대한 기존 최대 두 번의 재시도는 유지합니다.

## 검증

- 신규/변경된 시간 제한·진행 관측 검사 8개 통과. 작업자 이벤트 루프를 7초간 막은 상태에서도 부모가 탐색 진행 기록을 읽고 작업 결과를 한 번만 저장하는 통합 검사를 포함합니다.
- 기존 워커 배정·메모리 자동 조절·중단 경계·충돌 복구 검사 14개 통과.
- 기존 성능 계측 검사와 진행 관측 검사 재실행 통과. 기록 기능의 실패가 계산 반환값이나 원래 오류를 바꾸지 않는 것을 확인했습니다.
- 관련 스크립트 구문 및 공백 검사 통과. 저장된 세대 6 수집 지문과 현재 엔진 지문이 일치합니다. 규칙·난수·가중치·학습 목표를 변경하지 않았습니다.

## 실행 중인 학습에 적용

`data/ai/retrain-run-c-20260905-051719`의 기존 결과 29개를 보존합니다. 진행 중인 16개 작업은 저장 경계까지 완료하도록 요청했습니다. 별도 인계 프로세스가 종료 상태와 실행 중복, 저장된 데이터 호환성을 확인한 뒤 같은 디렉터리·시드·가중치로 새 코드를 실행합니다. 초기 4개, 최대 16개 자동 조절과 메모리 여유 기준 4 GiB를 유지합니다.

새 실행은 기존 결과 재사용, 기본 제한 0, 자동 조절 설정, 실제 계산 진행 횟수가 확인된 경우에만 `verified`로 기록합니다. 실제 인계 상태는 실행 디렉터리의 `progress-monitor-handoff.json`에서 확인합니다. 이전 실행은 종료·인계 전까지 메모리에 로드된 기존 코드를 사용합니다.

이번 변경은 작업을 조기에 버리는 문제와 진행 관측을 다룹니다. 경기 복사·합법 행동 검사 자체의 계산 비용이나 새 모델의 승률을 개선했다는 검증은 아닙니다.
