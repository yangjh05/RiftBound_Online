# 교정 사례 수집 보완 — 2026-09-28

사용자 요구: 교정 사례 수는 늘리되, 옳다고 판단할 근거가 있는 행동만 교정 대상으로 삼는 기준을 낮추지 않는다.

## 변경 범위

- 기존 `public-growth-development-v4` 교사를 그대로 호출한다. 멀리건의 기대 전개 점수 차이 0.75, 성장의 구체적인 다음 턴 전개 이득 0.5 기준을 유지한다.
- 즉시 유닛 전개·이동이 가능한 장면, 점수 경쟁상 위험한 장면, 반응 자원 부족, 계산이 완결되지 않은 장면에 대한 기존 성장 제외 규칙을 유지한다. 수를 맞추기 위해 이를 해제하지 않았다.
- 추가 성장 수집에서는 상대 대응 분석이 기존 추천과 모순되거나, 준비 자원·공개 활성 능력이 있는 상대의 대응 평가를 얻지 못하면 제외한다.
- 기존 교정 수집에 더해 최근 8회차의 일반 자기대전에서 회차당 4경기(원래 학습용 3, 검증용 1)의 초반을 재현한다. 저장된 상태와 선택 행동의 입력 표현이 일치해야 하며, 재현 실패 시 해당 구간의 사례는 전부 폐기한다.
- 등록된 6개 기준 덱마다 새 시작 경기 4개를 추가 검사한다. 성장 효과가 있는 덱에는 성장 카드가 실제 시작 손패에 들어오는 합법적인 셔플 시드를 찾아 8개의 제한된 초반 경기를 추가 검사한다. 카드·룬·점수·손패를 임의로 바꾸지 않는다.
- 각 게임은 최대 96행동, 성장 검토는 최대 8회다. 시작 손패 전용 경기는 실제 행동 단계가 시작되면 끝낸다. 모든 후보를 교정 사례로 삼거나, 부족한 수만큼 강제로 채우지 않는다.

## 학습과 검증

- 새 `prospective-verified-opening-growth-supply-v1` 프로토콜을 저장 경계 이후에만 적용한다. 기존 교사·모델 입력·게임 엔진·과거 수집 및 승급평가를 변경하지 않는다.
- 일반 경기의 원래 게임 단위 학습/검증 역할을 유지한다. 추가 생성 경기 역시 두 플레이어의 장면을 같은 역할로 유지하며, 역할은 손패와 추천 결과를 보기 전에 고정한다.
- 원본 계획·게임·정책 파일 지문과 수집 결과 지문, 교사의 비교 점수·계산 가정을 보존한다. 중단 후 동일한 입력과 결과를 확인하고 이어서 사용한다.
- 현재 교정용 경기와 추가 검증 사례를 별도 검사한다. 추가 사례의 평균 향상이 기존 검증의 악화를 가릴 수 없다. 이전 유형별 검증, 덱별 검증, 자원 교정 검사와 12회 갱신 상한도 유지한다.
- 정책 모방 학습에만 사용한다. 승리 보상, Q값 정답, 승급 통과 근거를 생성하지 않는다. 짧은 교정 구간을 완결된 경기라고 기록하지 않는다.

## 정확성의 한계

교사 판정은 명시된 범위의 비교다. 멀리건은 자기 덱에서 가능한 교체를 적분한 초반 전개 평가이며, 성장은 공개정보와 알고 있는 다음 턴 배치를 비교한다. 모든 장면의 전역 최적성이나 최종 승리를 증명한 것으로 표현하지 않는다. 이 범위에서조차 충분한 차이를 확인하지 못한 경우는 학습 사례를 만들지 않는다. 성장 표본이 계속 적더라도 정답 기준을 낮춰 늘리지 않는다.
