# AI 학습 처리 시간 개선 검증 — 2026-09-16

## 변경 범위

- 자가 대전 수집은 고정된 논리적 경기 번호·난수·모델·32경기·4 epoch를 유지한다. 물리적 워커의 초기 개수만 현재 할당량과 가용 메모리로 결정한다. 각 새 워커에 최소 1.2 GiB를 계산하고 4 GiB 여유 메모리를 남긴다. 메모리 값이 불명확하면 1개로 시작하며, 이후 기존 동적 증감 로직을 사용한다.
- 전술 보강은 기존 10경기와 학습/검증 분할, 난수, 2 epoch를 유지한다. 자가 대전이 사용하지 않는 수집 할당량 내에서 기존 프로세스 풀로 경기들을 실행한다. 저장 후 원래 경기 번호 순서로 읽어 학습 입력 순서를 보존한다. 이미 저장된 경기는 출처를 검증하고 재사용한다.
- 수집 풀은 완료된 워커의 실제 종료까지 기다린 뒤 할당량을 반환한다. 종료 요청 후 5초 처리는 이미 끝난 프로세스의 정리에만 적용하며 경기 제한 시간이 아니다.
- 승급 평가에서는 기존 `lean` 추론을 사용한다. policy와 action-Q를 결합한 행동 확률 및 GRU 기억 계산은 같은 함수를 사용한다. 행동 선택에 사용되지 않는 teacher proposal, 상태 가치, 진단 및 belief 출력과 불필요한 이력 보관만 생략한다. 지불 계획의 별도 가치 평가는 유지한다. `fullInference: true`로 기존 계산을 비교할 수 있다.
- 전체 할당량은 controller 1, audit 6, evaluation 1, collection 8로 최대 16이다. 평가 경기의 병렬화나 통계 기준 변경은 포함하지 않는다. 모델 크기, 학습 경기 수, PPO 설정, 승급 기준은 바꾸지 않는다.

## 동등성 및 회귀 검증

- `tests/ai-throughput.test.mjs`: 메모리 여유분, 할당량 0에서의 재개, 최대 16개 제한, 종료 전 자리 재사용 방지, 중단 후 재개, 완료 순서와 학습 순서의 분리, 오염된 출처 거부, 확률·표본 행동·GRU 기억의 정확한 일치를 검사한다.
- 관련 회귀 테스트 53개, 기존 신경망 테스트 중 평가/프로세스 풀 관련 27개가 통과했다.
- 실제 268세대와 211세대를 사용해 5개 덱별 2경기씩 기존 추론과 경량 추론을 실행했다. 10경기 모두 자연 종료했고 전체 경기 요약이 정확히 일치했다. 총 시간은 기존 159.14초, 경량 149.91초로 이 단회 측정에서는 약 5.8% 감소했다. 이 수치는 전체 학습 처리량 개선율이 아니다.
- 262세대의 실제 전술 보강 2경기(세트·마이)는 전장 설정 난수와 임시 식별자용 난수·시계까지 통제했을 때 순차/병렬 출력이 `deepStrictEqual`로 정확히 일치했다. 학습 31개, 검증 23개 표본의 상태·행동 인코딩, 라벨, GRU 기억, 순서 및 경기 결과를 모두 포함한다. 순차 58.21초, 워커 2개 병렬 40.57초로 이 단회 측정에서는 약 30.3% 감소했다. 운영의 워커 8개 또는 전체 학습 처리량 개선율을 뜻하지 않는다. 난수 고정은 테스트 전용 워커에서만 수행하며 운영 학습에 사용하지 않는다.

### 기존 보강 경기의 재현성 제한

75회차의 보강 경기 10개를 저장 당시 모델로 다시 실행했으나 과거 자료와 완전히 일치하지 않았다. 원인을 확인하기 위해 기존 순차 수집 함수를 같은 모델·게임 시드로 두 번 실행하자, 이 역시 202/180개 행동과 서로 다른 승자를 만들었다. 첫 입력 차이는 전장 카드 인코딩에서 나타났다. `createGame`의 `setupRandomValues`는 별도 `random` 인자가 없으면 전역 `Math.random`으로 생성되는데, 기존 보강 수집 함수는 `randomSeed`만 전달한다. 엔진 임시 식별자에도 전역 난수와 시계가 사용된다.

따라서 게임 시드만 맞춘 과거 자료와의 비교를 병렬화 동등성 증거로 사용하지 않는다. 모든 외부 난수 조건까지 통제한 비교를 별도로 실행한다. 이번 성능 개선은 운영 환경의 기존 난수 분포나 전장 선정 규칙을 변경하지 않으며, 과거 자료를 결정론적 자료로 재표기하지 않는다. 이 제한은 기존 순차 수집에도 존재한다. 재현 자료는 `nondeterminism.json`과 `probe.mjs`에 있다.

## 기존 자료 보존

판단에 관계된 소스 변경은 `evaluateNeuralModels`의 추론 세션 구성 한 곳뿐이며, 변경 전 사본과 정확히 비교한다. 검증된 전체 소스 지문만 `equivalent-evaluation-inference-v1` 호환 항목으로 등록한다. 이후 다른 AI/엔진 변경은 다른 지문이 되므로 이 호환 항목으로 승인되지 않는다.

기존 설정 파일과 저장된 경기, 모델, 승급 평가 요청을 수정하거나 다른 엔진의 자료로 재표기하지 않는다. 재개 직전 모델 및 진행 중 평가 파일의 SHA-256을 저장하고 재개 후 다시 확인한다. 고정된 입력의 동등성을 검증한 것이며, 작업 완료 시점에 따라 사용 가능한 감사 자료가 달라질 수 있으므로 향후 전체 학습 경로가 비트 단위로 같다는 주장은 하지 않는다.
