## 10% 배정 방식

회차당 32경기를 유지하고, 기존의 좌석·선공 조건이 완성되는 8경기 묶음을 사용한다. **5회차 160경기마다 16경기가 빅토르 교차 대전**이다. 일부 회차는 8경기, 나머지 회차는 0경기다. 첫 편입 회차에는 한 묶음이 배정된다.

빅토르의 상대는 기존 기준 덱 6개를 순환한다. 오로라 마이와 비오로라 마이는 서로 다른 덱으로 포함한다. 각 묶음은 빅토르가 두 좌석과 선공·후공 조건을 모두 경험한다. 두 플레이어 모두 현재 본학습 모델로 플레이하므로, 빅토르를 사용하는 방법과 상대하는 방법이 모두 새 on-policy 자료가 된다.

기존 경기 단위 학습/검증 분리를 그대로 사용한다. 묶음당 검증 1경기와 학습 7경기이며, 검증 경기의 두 플레이어 자료 모두 PPO 학습에서 제외된다. 교정 정답 기준, 과거 교정 복습, 기존 모델 승급 기준은 변경하지 않는다.

편입 대전은 기존 덱 탐색의 점수나 상대 순환 통계에 넣지 않는다. 기존 탐색은 기존 덱끼리의 비교 자료를 계속 사용한다. 기존 계획의 편입 대상으로 지정하지 않은 배정과 후보 덱은 그대로 보존한다.

별도 빅토르 가중치나 과거 PPO 궤적을 현재 본학습에 병합하지 않는다. 별도 후보 및 학습 자료는 보존하며 독립 학습도 계속한다. 이번 구현은 빅토르 덱의 제한적 교차 대전 편입이다. 별도 후보를 고정 상대나 교사로 사용하는 작업은 포함하지 않는다.

**10% 이상 자동 확대하지 않는다.** 기존 덱과 교정 유지율을 확인한 뒤 추가 변경으로 결정한다.
