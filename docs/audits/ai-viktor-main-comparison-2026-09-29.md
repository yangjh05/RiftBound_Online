# 빅토르 별도 후보와 최신 본학습 모델 직접 비교

사용자는 두 모델의 직접 미러 및 같은 상대·조건의 교차 대전 비교를 승인했습니다. 2026-09-29 17:29 KST부터 별도 평가를 실행합니다. 본학습과 빅토르 연속 학습은 계속합니다.

## 고정 대상과 해석

- 별도 후보: 빅토르 1510세대, 1490세대에서 출발해 빅토르 미러 640경기를 추가 학습한 모델.
- 본학습 비교본: 요청 시 최신 저장본인 1542세대, 누적 47,135경기.
- 이후 두 run의 세대가 증가해도 이 평가의 모델을 바꾸지 않습니다.
- 두 저장본의 실제 바이트 SHA-256 및 세대, 실행 코드 raw 지문, 공개정보 검토 설정과 전체 시드를 `plan.json`에 고정합니다.
- 양쪽에 같은 `bounded-public-runtime-review-v5`(48 previews/4 candidates)를 적용합니다. 기존 본학습 평가 설정과 일치함을 확인했습니다.
- 이는 우열을 알아보기 위한 진단 평가입니다. 승급, 가중치 병합, 교정 정답 채택 또는 본학습 데이터 편입을 자동 실행하지 않습니다.

## 320경기 구성

- 빅토르 미러 직접 대전 64경기: 별도 후보 vs 본학습 비교본.
- 카이사·세트·비오로라 마이·오로라 마이 교차 256경기.
- 각 상대 덱마다 본학습 비교본을 고정 상대 AI로 사용합니다. 평가 주체는 본학습 비교본과 별도 후보 각각이며, 같은 시드/좌석/선공/덱 배정을 사용합니다.
- 교차전에서는 평가 주체가 빅토르를 쓰는 경우와 상대 덱을 쓰는 경우를 나눠 집계합니다. 덱 파워에 따른 승률 차이를 모델 향상으로 혼동하지 않습니다.
- 각 덱·역할·모델당 16경기(4개 시드 블록)인 초기 진단입니다. 이 표본만으로 작은 차이나 통합 안전성을 확정하지 않습니다. 미완료 전후 쌍은 승률 차이 계산에서 제외합니다.
- 같은 시드의 좌석/선공 변경 경기는 독립 표본으로 취급하지 않습니다. 보고서에 완료된 블록별 차이를 기록합니다.

## 실행과 보존

- 실행 준비/감독: `.tmp-ai-viktor-main-comparison-20260929/`.
- 평가 자료: `data/ai/viktor-main-comparison-20260929-g1510-g1542/`.
- 동결 모델: 해당 디렉터리의 `inputs/main.json.gz`, `inputs/pilot.json.gz`.
- 계획: `plan.json`; 프로세스: `supervisor.json`, `worker-0.json`, `worker-1.json`.
- 각 경기: `games/<job>-<offset>.json`; 결과: `report.json`.
- 보고서 재생성: `node .tmp-ai-viktor-main-comparison-20260929/run-deck-pilot-comparison.mjs data/ai/viktor-main-comparison-20260929-g1510-g1542/plan.json report`.
- 모델/엔진/검토 로직/조건이 다른 경기, 비정상 종료·강제 판정 경기, 중복 경기는 실패 처리합니다. 재개 때 같은 계획에서 완료된 경기만 재사용합니다.

## 자원

- 기존 본학습 컨트롤러 PID 27296, 빅토르 컨트롤러 PID 30688을 재시작하지 않았습니다.
- 기존 별도 학습 예약을 3에서 5슬롯으로 임시 확장합니다. 3슬롯은 빅토르, 2슬롯은 비교 평가입니다.
- 본학습 프로세스가 11개 이하인 것을 연속 확인한 뒤 비교 워커 2개를 시작합니다. 합계 최대16, 저장된 Normal 우선순위와 native TensorFlow 1스레드를 유지합니다.
- 비교 프로세스가 모두 끝난 후 자신이 소유한 예약인 경우에만 원래 3슬롯으로 복구합니다. 한 워커라도 살아 있으면 예약을 줄이지 않습니다.
- 중단 복구는 비교 워커와 감독 프로세스가 모두 종료됐는지 확인한 다음 같은 `run-comparison.ps1`을 실행합니다. 기존 학습이나 비교 파일을 지우지 않습니다. 살아 있는 프로세스를 중복 실행하지 않습니다.
