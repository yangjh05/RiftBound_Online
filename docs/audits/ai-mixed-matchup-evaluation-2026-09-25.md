# 미러전과 다른 덱 대전의 승급 평가

## 변경 목적

덱 탐색 학습은 이미 다른 전설과 같은 전설의 다른 목록을 사용하지만, 기존 v3 승급 평가는 전설별 대표 5개 목록의 미러전만 측정했다. 이 평가만으로 다른 덱 상대 실력 향상을 확인할 수는 없었다.

새 v4 평가는 기존 학습 run과 신경망을 유지하면서 고정된 6개 덱을 평가한다. 세트, 애니, 카이사, 레오나와 **오로라 3장 마이**, 사용자가 제출한 **오로라 없는 마이**를 별도 덱 ID로 유지한다. 두 마이의 학습도 기존 curriculum에서 계속 돌아간다. 적용 전 현재 run의 학습용 덱 집계는 비오로라 399경기, 오로라 210경기였으며 시험 덱으로 지정된 슬롯은 각각 128, 120개였다. 이 수치는 평가 결과나 독립 실력 인증이 아니다.

## 대전과 판정

- 6개 동일 목록 미러 + 15개 서로 다른 목록 조합 = 한 바퀴 21개 조합. 서로 다른 마이 목록끼리의 대전도 포함한다.
- 각 조합은 후보가 맡는 덱 두 방향, 좌석 두 방향, 선후공 두 방향을 교차한 8경기다. 같은 목록 미러에서는 두 시드를 사용한다.
- 기존 `evaluateNeuralModels`의 `cross-deck-matrix-v1`을 조합별로 호출한다. 공용 게임 루프, 추론, 메모리, 지불 처리, 불법 행동 검사에 별도 구현을 만들지 않는다.
- 두 4경기 묶음은 서로 다른 시드를 쓰며 합친 8경기가 하나의 통계 관측이다. 8경기를 독립 관측 8개로 세지 않는다. 원래의 혼합 betting 계산을 사용하고, 모든 조합이 한 번씩 포함된 168경기 단위에서만 판정한다. 추정 대상은 고정된 **덱 목록 조합별 동일 가중 평균**이다. 마이 목록 두 개가 있으므로 전설별 동일 가중 평균은 아니다.
- 최소 672경기부터 판정한다. 유망하지 않은 후보는 840/1,176경기 검사에서 끝낼 수 있다. 기본 1,512경기, 연장 검사 2,016경기, 최대 2,352경기다. 원래 2,400경기 상한을 늘리지 않는다. 고정 기준 AI 비교는 최대 840경기이며 승급하지 않는다.
- 통계적 우위, 전체 관측 승률 52% 이상, 조합별/덱별/좌석별/선후공별 관측 하한 40%를 함께 검사한다. 미러전과 다른 목록 대전 각각 관측 승률 50% 이상도 요구한다. 한쪽 성적 상승으로 다른 쪽 하락을 가리지 못하게 한다.
- 이 하한은 관측된 퇴보를 막는 검사이며, 32경기로 각 상성의 우위를 확정하는 검정이 아니다. 오차 예산 0.02는 비교별 양측 anytime 기준이며, 반복되는 모든 후보에 대한 평생 오차 보장은 아니다.

## 보존과 재개

`mixed-evaluation-protocol.json`의 `afterOrdinal` 이후 새로 예약되는 평가에만 적용한다. 기존 평가의 요청, 덱, 시드, 판정 규칙, 저장된 경기와 결과를 변경하지 않는다. 이미 살아 있는 평가 워커는 계속 실행하고 새 controller가 그 lock을 인계받는다. 예약 당시 프로토콜과 덱 ID를 해시로 고정하므로 재시작 후 덱이나 조건이 바뀌면 실패한다.

새 실행 코드는 `.tmp-ai-mixed-evaluation-20260925/runtime`, 실행기는 같은 폴더의 `run-training.ps1`이다. 기존 검증 runtime을 복사하고 평가용 scripts 및 대시보드 서버 8개 파일만 추가/변경했다. 엔진·신경망 원본 파일은 전부 동일하다. 713개 실행 파일의 해시 manifest와 다음 엔진 지문을 재개 전 검사한다.

`sha256:04f65ac877be0e76d4ac11ba9dd7dda27feb60613901ad1b76620482bbc2fd7a`

같은 run, 기존 모델과 optimizer, 수집 자료, 두 마이 기준 목록, 최대 16워커 및 저장된 normal 우선순위를 유지한다. 호환 지문을 새로 허용하거나 자료에 다른 지문을 붙이지 않았다.

## 검증

- 평가 계약·이전 판정·재개 무결성·대시보드 55개 검사 통과.
- 실제 두 마이 목록의 curriculum 배정과 기존 덱 탐색 10개 검사 통과.
- 검증 항목: 전체 21개 조합, 두 덱 방향/좌석/선후공의 대칭, 시드 충돌, 강한 덱만 번갈아 맡으면 정확히 50%, 두 평가 집단의 퇴보 차단, 최초 종료 시점 재현, 부분 저장 재개, 요청 위조 차단, 이전 v1/v2/v3 평가 보존, 신경망 실행기의 저장 경기 재사용, forecast 조합 균형.
- 실제 현재 모델로 카이사–비오로라 마이 8경기 및 두 마이 간 8경기가 모두 자연 종료했고 재사용 무결성을 확인했다. 실행 결과와 활성화 시점은 `.tmp-ai-mixed-evaluation-20260925/smoke-result.json`, `activation.json`, `resume-verification.json`에 기록했다. 작은 실행 검사는 호환성 검사이며 실력 향상 증거가 아니다.

141회차 / 1201세대 저장 후 같은 run에서 142회차 수집을 재개했다. 65번 평가는 기존 방식 그대로 이어가고 66번부터 혼합 평가를 사용한다. 재개 후 새 수집 경기 저장과 기존 평가 경기 증가, 이전 경기 61개 내용 불변, 대시보드 HTTP 200을 확인했다. 실제 대시보드와 가상 21조합 화면의 데스크톱·390px 화면 검사에서도 브라우저 실행 오류가 없었다.

대시보드는 미러/다른 목록 승률, 조합별 경기 수와 승률, 두 마이 목록을 따로 표시한다. 미러 평가에서 혼합 평가로 전환된 직후의 승률 차이를 직접적인 증감 수치로 표시하지 않는다.
