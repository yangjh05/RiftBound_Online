# 공개정보 기본 행동을 초기화한 뒤 반응 위험을 학습하는 구조

2026-09-15. 실행 우선순위 Normal, 전체 계산 슬롯 상한 16.

## 적용한 동작

- `src/ai/tactical-baseline.mjs`는 실제 엔진으로 상대 무반응 시의 결과를 계산한다. 점수, 전장 지배, 유닛과 부착물, 손패 소모, 지불 자원, 아군 손실을 함께 계산한다. 이 가치 가중치는 임시 시범 정책이며 승률이나 확정 정답이 아니다.
- 공개되지 않은 상대 손패·매복 카드의 정체와 양쪽 덱 순서를 제거한 복제 상태를 사용한다. 알 수 없는 상대 선택이나 지원하지 않는 복합 처리는 추천하지 않는다. 후보 8개, 후보별 상태 40개로 비용을 제한한다.
- 기존 전투 지원 계획을 통해 주문 선언·대상·지불까지 이어진 결과를 계산한다. 기존의 무의미한 패배 전투 제한은 유지한다.
- 유리한 이동이 있다는 이유로 `endTurn`을 제거하던 두 제한을 해제했다. 기본 정책을 배운 뒤에도 자원 보존과 타이밍 조절을 선택할 수 있다. 즉시 확정 승리 등의 기존 제한은 별개로 유지한다.

## 일회성 초기 학습

누적 111회차, 3,552경기의 학습을 이어받은 체크포인트를 사용한다. 새 행동 계약에서 16경기를 진행하며 기본 행동과 그에 필요한 후속 선택을 시범으로 기록한다. 완주하지 못한 경기는 사용하지 않는다. 경기 단위로 학습 12경기와 별도 확인 4경기를 나누고, 최대 8회 학습 중 별도 확인 손실이 가장 낮은 모델을 고정한다. 개선이 전혀 없으면 자동 중단한다.

기억을 처리하는 GRU와 V·Q·상대 패 추정·진단·교사 제안 헤드의 **가중치**를 고정하고, 상태 및 행동 투영층과 행동 편향만 학습한다. 공유 입력이 바뀌므로 모든 헤드의 출력이 같다는 뜻은 아니다. 별도 시범 샘플의 기존 기억을 그대로 사용할 수 있고, 승패·상대 비공개 카드의 가짜 라벨로 학습하지 않는다.

시범은 초기 선호를 형성하는 데만 사용한다. 이전 경기 수에 시범 결정을 더하거나, 과거 기록을 새로운 정책이 생성한 경기로 바꾸지 않는다. 추론에 고정 점수 보너스를 더하지 않아 실제 선택 확률과 PPO가 계산하는 확률이 일치한다.

## 이후 자가대전과 평가

- 기존 32경기 단위 자가대전 및 PPO를 이어간다. 상대가 실제로 반응한 결과와 최종 승패를 통해 초기 선호를 수정할 수 있다.
- 이미 예산이 배정된 교사 검토에서 기본 추천 행동과 보류 행동을 우선 비교 대상으로 넣는다. 기존의 동일한 추정 상대 상태 및 후속 난수 조건에서 비교한다. 상대 반응을 한 번 맞았다는 이유로 행동을 오답 처리하지 않는다.
- 교사 검토는 기록용이다. 공개정보 임시 가치와 제한된 시뮬레이션은 승률 증명이나 강제 교정 라벨이 되지 않는다. 독립 섀도우 검증 조건도 유지한다.
- 고정된 초기 모델과 1회차 및 이후 8회차마다 40경기 진단 대전을 한다. 5덱 각각 8개 조건을 비교하며 승급 판단에는 사용하지 않는다. 별도의 기존 챔피언 상대 최대 1,024경기 승급 검증을 유지한다.
- 초기화 전후 확인 손실/행동 일치율은 시범을 얼마나 배웠는지 보여 준다. 실제 승률 향상이나 전반적 실력 향상의 증거는 별도 대전으로 확인해야 한다.

관련 회귀 검증 107개와 신경망 집중 검증 9개가 통과했다. 다음을 포함한다.

- 같은 효과라면 지불 비용이 작은 행동을 선호한다.
- 유리한 전장 점령과 보류 행동이 함께 남는다.
- 상대 비공개 카드 정체와 덱 순서가 기본 추천을 바꾸지 않는다.
