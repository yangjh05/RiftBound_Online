# 177세대 사람 대전: 가속·사용 순서·제거 수단 분석

리포트 `0b821399-8292-4a36-8f6d-51f350a9737d`, 설명 `AI분석 2회차임. 버그 아님`. 사용자가 모델을 177세대로 확인했습니다. 양측 카이사 덱이며 p1이 사용자, p2가 AI입니다. 최종 점수는 사용자 8:3 AI입니다.

## 근거와 재현 범위

인증된 서버 접속으로 요청받은 리포트 하나를 읽어 로컬에 보존했습니다. 180개 명령을 모두 성공적으로 재실행했고 누락된 명령은 0개입니다. 마지막 20개 저장 장면과 재현 상태의 점수, 카드 위치·위력·피해·준비 상태, 손패·덱, 룬·생성 자원, 우선권 및 게임 난수 상태를 비교해 모두 일치했습니다. 화면 오류 기록은 없습니다. 벽시계 기반 임시 식별자와 UI 표시까지 원본 전체 바이트가 같다는 뜻은 아닙니다.

독립 대안은 초기 상태부터 해당 명령 직전까지 다시 재생한 뒤 엔진의 실제 행동과 지불·전투·종료 절차로 실행했습니다. 대안끼리의 결과를 누적한 전체 경기 재시뮬레이션은 아닙니다. 상대 무반응 분기와 실제 상대 손패의 연막 반응 분기는 구분했습니다. 분석 중 운영 코드, 학습 가중치, 학습 자료, 평가 기준은 변경하지 않았습니다.

## 1. 천 꼬리 감시자의 가속 선택이 자동 지불 경로에서 빠져 있음

5턴, 명령 164~168입니다. 사용자는 6점, AI는 3점입니다. 사용자의 위력 7 감시자가 타곤의 봉우리를 지배하고, 자운 뒷골은 비어 있습니다. AI는 준비된 룬 8개로 감시자를 냈습니다.

실제 비가속 지불은 에너지 7과 정신 힘 1입니다. 지불 후 룬 7개 중 하나만 준비되어 있고, 감시자는 본진에서 탈진 상태입니다. 사용자의 감시자는 이번 턴에만 위력 7에서 4로 약화됐습니다. AI가 턴을 끝내면서 약화는 사라졌고, 사용자는 유지 점수로 7점에 도달한 다음 가속 카이사로 빈 전장을 정복해 8점으로 승리했습니다.

가속을 선택한 반사실 분기의 실제 엔진 비용은 에너지 8과 정신 힘 2이며, 지불에 성공했습니다. 같은 룬에서 에너지를 생성한 후 힘으로 재활용할 수 있으므로 준비 룬 8개로 지불 가능합니다. 카이사 전설의 생성 힘은 주문 전용이라 감시자 지불에는 사용하지 않았습니다.

| 분기 | 확인된 결과 |
|---|---|
| 실제 비가속 소환 → 종료 | 감시자는 본진에 남고, 적의 일시 약화는 소멸. 이후 실제 로그에서 8:3 패배 |
| 가속 → 타곤 공격, 상대 무반응 | 아군 7 대 적 4로 적 감시자 처치, 점수 6:4, 전장 지배 이전. 다음 턴 상대 유지 점수를 막고 타곤 효과로 아군 룬 2개 준비 |
| 가속 → 빈 자운 정복, 상대 무반응 | 즉시 6:4, 감시자가 전장에 진입. 다음 상대 턴 시작은 7:4 |
| 가속 → 타곤 공격, 사용자 연막 반응 | 사용자는 실제 준비 룬 2개와 손패의 연막으로 AI 감시자를 위력 3으로 낮출 수 있음. 적 감시자는 위력 4여서 AI 감시자가 사망 |

따라서 타곤 공격의 승리를 보장할 수는 없습니다. 빈 전장 진입까지 포함해 가속의 비용과 후속 행동, 반응 위험을 비교해야 했습니다. 실제 상대 손패는 반사실 검증에만 사용했으며 AI가 당시 이를 알았다고 가정하지 않습니다.

원인은 신경망이 반응 위험을 보고 가속을 포기했다는 증거가 아닙니다. `handleAiTurnWorkerRequest`는 지불 중이면 신경망 정책 호출 전에 `choosePaymentPlan`을 반환합니다. `choosePaymentPlan → greedyPaymentPlan → planPaymentActions`는 현재 선택된 비용을 지불하며 가속 선택을 켜는 행동을 만들지 않습니다. 자원 생성 능력 비교도 이 선택을 추가하지 않습니다. 일반 지불 탐색 함수 `enumeratePaymentPlans`에는 선택 비용 후보가 있으나 현재 실행 경로에서 호출되지 않습니다.

자가 대전도 지불 단계에서 `resolvePlannedPayment`를 호출하고 정책 결정 단계를 건너뜁니다. 이 경로를 유지한 채 학습량만 늘려서는 자발적으로 가속을 선택하는 정책이 생기지 않습니다. 이 제한은 감시자뿐 아니라 자동 지불에 묶인 선택 비용에 공통으로 적용됩니다. 정면승부의 준비 진입 순서 보완은 이 가속 선택 경로까지 다루지 못했습니다.

## 2. 같은 유닛 두 장의 사용 순서로 에너지 2 낭비

3턴 명령 86~92에서 AI는 녹서스의 기대주를 먼저 내고 설교하는 요들을 냈습니다.

| 순서 | 총 에너지 | 같은 두 장을 낸 후 준비 룬 |
|---|---:|---:|
| 실제: 기대주 4 → 요들 3 | 7 | 0 |
| 대안: 요들 3 → 군단 적용 기대주 2 | 5 | 2 |

무반응 엔진 재현에서 최종 두 유닛, 손패 및 요들의 드로우 결과가 같고 준비 룬 두 개가 더 남았습니다. 당시 AI 손에는 연막도 있었습니다. 사용 순서에 따른 공통 비용 감소를 다음 행동까지 연결해 비교하지 못한 사례입니다. 가속과는 별도의 정책·계획 문제이며 엔진의 군단 비용 계산 자체는 정상입니다.

## 3. 주문과 전투로 처리할 대상을 잘못 나눔

4턴 명령 94~116입니다. 상대 전장에는 위력 2 뾰로통한 포로와 위력 4 녹서스의 기대주가 각각 있었고, AI 본진에는 준비된 기대주 4와 요들 2가 있었습니다.

실제 순서는 공허추적자 4피해로 포로 제거 → 기대주로 빈 타곤 정복 → 낙성 두 발로 상대 기대주 제거 → 요들로 빈 자운 정복입니다. 포로의 굴절 비용도 지불했습니다.

대안은 공허추적자로 상대 기대주 제거 → 아군 기대주 4로 포로 2를 전투 처치 → 요들로 빈 자운 정복입니다. 같은 자운 버리기 선택을 적용했습니다.

| 상대 무반응 비교 시점 | 실제 | 대안 |
|---|---:|---:|
| 점수 | 5:3 | 5:3 |
| 아군 전장 유닛 | 기대주 + 요들 | 기대주 + 요들 |
| 남은 룬 | 6 | 9 |
| 준비 룬 | 4 | 6 |
| 낙성 보유 | 사용함 | 손에 보존 |

세 룬의 차이는 포로 굴절 비용 한 개와 낙성의 힘 두 개를 피한 결과입니다. 낙성의 에너지 2도 아낍니다. 상대 반응이 없으면 같은 전장 결과에 더 적은 자원을 쓰는 구체적인 경로가 존재했습니다. 실제 상대는 반응할 자원이 있었으므로 반응 가능한 전투 경로가 모든 상대 대응에 대해 엄밀히 우월하다는 주장은 아닙니다.

이번 낙성을 같은 기대주에 두 번 쓴 것 자체는 첫 리포트의 요들 중복 지정과 다릅니다. 위력 4를 기본 피해 3 한 발로 처치할 수 없어 두 발이 필요했습니다. 앞선 제거 대상 배분과 전투 계획이 개선 대상입니다.

## 4. 전술 예시 생성기가 잘못된 기본 행동을 추천할 수 있음

현재 전술 예시 생성기에 실제 명령 164 직전 상태를 넣으면 비가속 감시자 소환과 통과를 추천합니다. `publicTacticalValue`가 큰 유닛의 본진 가치를 즉시 인정하고, 미사용 일시 약화의 만료와 다음 턴의 추가 정복까지 이 장면에서 비교하지 않기 때문입니다. 재현된 단기 이득 점수는 약 3.15이며, 이는 승률이 아닙니다.

종료까지 보는 특별 처리는 상대의 현재 점수에 유지 점수만 더해 즉시 승리하는 상황을 기준으로 합니다. 여기서는 6 + 1 = 7이므로 활성화되지 않습니다. 실제 패배는 유지 한 점 뒤의 빈 전장 정복 한 점으로 일어났습니다. 정면승부나 이미 활성화된 준비 진입 플래그의 후속 이동은 다루지만, 아직 선택하지 않은 가속을 유닛 사용과 연결하지 못합니다.

이 특정 장면이 177세대의 학습 예시에 실제 포함되었다는 증거는 아닙니다. 그러나 현재 예시 생성 방식이 같은 실수를 추천할 수 있다는 것은 직접 재현했습니다.

## 보완 우선순위

1. 가속 등 선택 비용을 신경망이 비교 가능한 전략 선택으로 연결하고, 가속 후 실제 이동·전투·득점까지 비용 포함 비교합니다. 물리적인 룬 선택만 자동 지불로 남깁니다. 이미 준비 진입이 보장된 경우 추가 가속 비용을 낭비하지 않아야 합니다.
2. 군단 등의 공통 비용 감소를 실제 엔진으로 두 행동 순서에 적용하여 자원 절약과 구체적인 반대 순서 이득을 비교합니다.
3. 단일 주문의 처치 가치 외에, 다른 적을 전투로 처리하면서 같은 전장 결과를 얻는 조합을 비교합니다.
4. 전술 예시에서 일시 효과 만료와 가까운 상대 득점 경로를 반영합니다. 기본 예시의 오류를 그대로 학습량으로 보완하려 하지 않아야 합니다.

이 분석은 승급 평가 결과를 변경하지 않습니다. 사람과의 한 경기로 일반 승률을 추정하지 않으며, 확인된 계산·선택 경로의 결함과 재현 가능한 전술 대안을 분리해 기록합니다.
