# 챔피언 출발 비교와 학습 기준점 관리

챔피언 상대 승률이 개선되지 않는 후보를 계속 이어서 학습하는 문제를 점검하고, 검증된 기준점으로 돌아갈 수 있도록 수정했습니다. 본학습은 기존 실행의 체크포인트와 자료를 이어 사용합니다. 별도 비교에서는 챔피언 1163세대와 본학습 480회차의 1805세대를 시작점으로 사용합니다. 이 변경 자체가 실력 향상을 입증하지는 않습니다.

## 본학습의 기준점

`learner-anchor-protocol.json`은 480회차 이후에 적용됩니다. 기준점은 현재 챔피언에서 시작하며, 실제 승급이 발생하면 해당 승급 모델로 갱신합니다. 한 후보가 졌다는 이유로 되돌리지 않습니다. 같은 학습 분기에서 32회 이상의 학습이 완료되고, 서로 다른 두 후보의 완료된 평가에서 챔피언 상대 승률 상한이 50% 미만일 때에만 기준점으로 복귀합니다. 과거 분기의 평가, 같은 후보의 중복 평가, 불확정 평가, 이전 챔피언 상대 평가는 이 조건에 포함하지 않습니다.

복귀는 다음 회차의 계획을 만들기 전에만 실행합니다. 이미 수집 중인 경기, 생성된 계획, 진행 중인 승급평가와 배포 챔피언은 수정하지 않습니다. 복귀 모델은 새 계보 파일로 저장하고 세대 번호를 증가시킵니다. 원본 후보, 교정 사례, 경기와 기존 체크포인트는 보존합니다.

별도 비교 후보가 새 확인평가를 통과하면 다음 계획 경계에서 학습 기준점으로 사용할 수 있습니다. 확인 결과의 실제 경기 기록, 예정된 덱·좌석·시드·공개정보 검토, 모델 행동 해시와 설정 해시를 다시 검사합니다. 비교 도중 챔피언이 바뀌면 이전 챔피언에 대한 결과로 교체하지 않습니다. 이는 학습을 이어갈 기준점의 선택이며, 정식 승급은 기존 평가를 다시 통과해야 합니다.

## 시작점 비교

두 후보는 각각 32경기씩 4회, 회당 최대 4에포크를 학습합니다. 상대 구성은 두 후보 모두 챔피언 1163세대 50%, 과거 챔피언 982세대 25%, 해당 회차 자기 자신 25%입니다. 덱과 시드, 학습 좌석, 학습량, 교정 자료 및 검증 조건은 대응시킵니다. 상대의 행동 궤적을 학습자의 PPO 자료로 사용하지 않습니다.

세트, 애니, 카이사, 비오로라 마스터 이, 오로라 마스터 이, 레오나, 빅토르를 사용합니다. 양쪽이 모두 끝나면 초기 모델과 학습 후보를 1163세대와 비교합니다. 선별평가는 덱별 미러 및 순환 교차 조합으로 모델당 112경기입니다. 실제 반영된 에포크가 없거나 공통 훈련 입력에서 평균 행동 확률 변화가 0.1% 미만이면 해당 새 후보의 대전을 생략합니다. 동일 가중치의 평가는 상대·규칙·시드까지 일치할 때만 재사용합니다. 이 확률 변화 기준은 계산을 줄이는 국소 선별 기준이지 실력 지표가 아닙니다.

선별에서 시작점 대비 개선과 챔피언 상대 50% 이상의 관측 승률을 보인 후보 중 하나만 고릅니다. 고른 뒤에 새로운 확인 시드로 후보와 원래의 1805세대를 각각 224경기 평가합니다. 시드 단위로 좌석·선후공·난수 교환을 묶어 차이를 계산하며, 독립 표본인 것처럼 좌석별 경기를 중복 계산하지 않습니다. 확인 조건은 28개 이상의 시드 묶음, 양의 승률 차이, 차이의 근사 2표준오차 하한이 0보다 큼, 후보 관측 승률 50% 이상입니다. 이 근사 구간은 정식 승급의 통계 보장을 대체하지 않습니다. 시드를 늘려 통과할 때까지 반복하지 않습니다.

미러는 8경기로 난수 배정까지 교환합니다. 두 덱의 교차 평가도 8경기로 양쪽 덱을 모두 운영합니다. 실제 엔진의 두 덱 행렬 선택이 교차 대전을 만들도록 시드를 고정했습니다. 전 조합 확인평가는 미러 7조합과 교차 21조합입니다.

## 교정 사례의 기억 상태

기존 교정 자료에는 과거 모델의 GRU 기억값만 있고 앞선 관측 순서가 없는 사례가 있습니다. 그 자료를 새 모델의 실제 경기 기억으로 재구성했다고 주장할 수 없습니다. 기존 정답과 보존 검사는 유지하며, 기록이 없는 이력을 추정하거나 0으로 채우지 않습니다.

새 교정 수집은 해당 플레이어가 실제로 관측한 전체 입력 순서를 함께 저장합니다. 검사와 복습에서는 각 모델의 현재 GRU로 그 순서를 다시 처리합니다. 상대 플레이어의 관측이나 현재 정답 장면을 과거 이력에 넣지 않습니다. 현재 GRU가 같을 때만 결과를 재사용하고, GRU 가중치가 바뀌면 캐시를 버립니다. 긴 이력은 32단계씩 나누어 계산하되 앞부분을 잘라내지 않습니다. 복습 기울기는 재계산한 기억에서 정답 단계에 적용하며, 가중치 변경 후 보존 검사는 다시 계산한 기억으로 수행합니다.

별도 비교에서는 같은 고정 챔피언으로 새 멀리건 교정 사례를 수집했습니다. 기존 훈련 136개·검증 131개를 유지하고, 이력이 있는 훈련 18개·검증 19개를 추가했습니다. 승리한 행동을 곧바로 정답으로 삼지 않습니다. 기존 교사의 비교 완료 조건, 이득 기준과 제외 조건을 유지하고 훈련·검증 간 같은 공개 입력의 중복 추가를 막습니다.

본학습의 재개 전에 이미 완성된 481회차 교정 파일은 다시 쓰지 않습니다. 본학습에서 이후 새로 수집하는 교정 파일부터 전체 이력을 저장합니다.
