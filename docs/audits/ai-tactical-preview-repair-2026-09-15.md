# 전술 예시 계산, 지속 학습 및 평가 예산 보완

2026-09-15. 기존 학습 가중치와 데이터 보존, Normal 우선순위, 전체 계산 프로세스 최대 16.

## 전술 계산

`src/ai/tactical-baseline.mjs`의 제한된 무반응 시뮬레이션에서 점령 후 선택 효과가 열리면 행동 전체를 계산 불가로 폐기하던 문제를 수정했다. 선택 가능한 트리거는 실제 엔진의 선언·거절 경로를 사용한다. 지원하지 못하는 자기 선택 분기가 있더라도 완전히 계산된 다른 자기 선택 분기를 보존한다. 계산 예산은 40상태·24단계로 유지하며, 미계산 분기의 존재를 결과에 명시한다. 상대의 필수 선택을 자기에게 유리하게 고르지 않는다. 상대의 추가 반응과 비공개 패·덱 순서를 근거로 삼지 않는다.

평가 8의 레오나 경기 9, 행동 147은 회귀 진단에만 사용했다. 수정 전 계산 불가였던 Discipline이 수정 후 공격자 c77을 대상으로 하는 우선 행동이 됐다. 자기 행동의 continuation에 주문 선언·대상 선택·전투 피해 배정·점령 후 선택의 거절까지 포함된다. 추가 반응이 없다면 점령하는 것을 실제 엔진으로 검증했다. 무반응 이득은 승률 정답이나 상대 반응을 포함한 우세 증거로 취급하지 않는다. 기존 합법 행동 및 보류 선택은 유지한다.

## 주기적 전술 연습

전술 예시는 최초 초기화에만 머물지 않도록 별도 사전 설정을 추가했다. 첫 적용은 전환 후 새 회차이고 이후 8회차마다 실행한다. 그 시점의 기존 학습 모델을 이어받아 새 시드의 같은 덱 연습 10경기를 생성한다. 다섯 덱마다 학습 1경기·검증 1경기이며, 한 경기의 모든 행동은 같은 분할에 둔다. 평가 경기 재현 파일과 보호된 Q 검증 자료는 이 코드에서 읽지 않는다.

정책에 한정한 지도 학습을 최대 2회 실시하고 독립 연습 경기의 행동 예시 적합도가 개선된 회차만 선택한다. GRU, 상태 가치, Q, 상대 패 추정 등 정책 외 가중치는 이 지도 학습으로 수정하지 않는다. 예시 부족·검증 적합도 미개선 시 기존 가중치를 유지한다. 이 검증은 전술 예시 적합도이며 실전 승률 개선의 증거가 아니다.

새로 조정한 정책을 **다음 PPO 경기 수집 전에** 고정하여, 이후 경기의 행동 확률과 원본 정책 해시를 새 정책에 맞춘다. 이전 정책으로 수집한 경기를 새 정책의 on-policy 경기라고 다시 표시하지 않는다. 초기 기본 모델과의 성장 비교 기준도 바꾸지 않는다. 경기와 체크포인트에는 원본 파일 해시, 사전 설정 해시, 시드 및 분할을 저장하여 재개 시 검증한다.

## 유망도가 낮은 평가의 조기 종료

이미 예약된 9번 평가는 기존 순차 계약을 그대로 유지한다. 별도 `evaluation-efficiency-protocol.json` 이후 새 예약에만 고정된 `futilityPolicy`를 넣는다. 기존 승급 증거, 최소 320경기, 덱·좌석 퇴보 제한은 그대로다.

800경기부터 400경기 간격으로, 누적 승률과 최근 400경기 승률이 모두 52% 이하인지 확인한다. 두 차례 연속 만족하면 `low-promise`로 종료한다. 최초 가능 시점은 1,200경기이며, 최근 성적이 회복되는 후보는 이 조건으로 종료하지 않는다. 50%가 지속되는 인공 입력은 4,000경기 대신 1,200경기에 종료한다. 이는 해당 경우 평가량 70% 절감이며 실제 모든 후보의 절감률은 아니다.

이 기준은 계산 자원을 배분하기 위한 휴리스틱이다. 실제로 조금 더 강한 후보를 놓칠 수도 있다. `inferiorityProven:false`로 기록하며 통계적으로 열세가 증명됐다고 주장하지 않는다. 새로운 승급 경로를 추가하지 않고 종료만 앞당기므로 기존 거짓 승급 제한을 완화하지 않는다. 결과 재구성은 최초 종료 시점을 고정하여 재시작 후에도 유지한다. 한도를 줄이기 위해 진행 중인 평가에 소급 적용하지 않는다.

## 기존 자료와 실행 호환성

동작 지문에 포함된 변경은 전술 예시 생성 모듈 한 파일뿐이다. 실제 엔진 규칙, 합법 행동 생성·필터, 신경망 순전파, 지불 정책, 고정된 섀도우 후속 행동은 변경하지 않았다. 기존 평가 8의 마스터 이·레오나 8경기를 수정 후 다시 실행해 모델·시드·좌석별 승자, 점수, 행동 수 및 식별 필드가 모두 일치함을 확인했다.

완전한 원본 소스 해시가 정확히 일치할 때만 `training-only-tactical-demonstration-v1` 호환 항목으로 기존 데이터 지문을 사용한다. 실제 평가 동작, 행동 목록, 저장된 학습 타깃이 유지된다는 세 조건을 필수로 검사한다. 다음에 다른 소스가 변경되면 이 항목은 매칭되지 않는다. 기존 경기나 모델을 새 계산 결과로 덮어쓰지 않는다.

관련 회귀 검증 86개가 통과했다. 전술 분기와 비공개 정보, 실제 반응, 정책 외 가중치 보존, PPO 동작 확률, 순차 통계, 데이터 분할, 조기 종료, 신규 예약 적용, 재개 및 지문 호환성을 포함한다. 운영 자료 보존 해시와 재현 기록, 실행 검증은 `.tmp-ai-tactical-repair-20260915`에 저장한다.
