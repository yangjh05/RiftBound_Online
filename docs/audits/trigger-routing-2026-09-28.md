## 검증 범위

- 카드 이름을 검사하는 개별 분기는 추가하지 않았습니다. 등록된 `timing:kind`와 공용 처리를 사용합니다.
- 추가 재현 테스트 22개가 통과했습니다. 정복의 전투 유무, 선택 거절, 탈진 여부,
  초과 피해 기준 양쪽, 사망 당시 혼자인 경우, 정상 비용 지불과 후속 진행을 확인합니다.
- 기존 엔진·효과·규칙 테스트를 포함한 664개 실행이 통과했습니다. 이후 상대 득점
  관찰의 중복 발동 방지 테스트 1개를 추가했고, 집중 테스트 22개 실행에 포함했습니다.
- 990장 카드 정적 검증, 685개 효과 쌍 검증 및 카드 변형 검증 3,984개가 통과했습니다.
- `validate:engine`에 등록 카드의 96개 명시적 발동 경로 검사를 추가했습니다.
  resolver 등록만 있고 실제 이벤트 수집에서 빠진 경우를 별도로 검사합니다.
