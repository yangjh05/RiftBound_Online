# Unleashed 전체 구현 계획과 완료 기준

## 결론

Unleashed는 **공식 소스 고정 → 공용 상태 기반 → 기믹군별 대표 카드 → 동일 효과군 일괄 등록 → UI와 한국어 → 비AI 전체 검증** 순서로 구현합니다. 카드 이름을 검사하는 분기는 두지 않으며, 같은 규칙은 같은 `timing:kind`와 공용 resolver를 사용합니다.

2026-08-29에 고정한 공식 본세트는 `UNL-001/219`부터 `UNL-219/219`까지 정확히 219장입니다. 현재 219장 모두 카드 레지스트리, 효과 명세, 비공식 한국어 이름·본문에 등록되어 있습니다.

## 정형화된 구현 순서

1. **공식 소스 고정** — 공식 갤러리의 번호·유형·비용·문구를 스냅샷으로 보존하고 Unleashed 및 이후 누적 정오표를 유효 문구에 반영합니다.
2. **효과 분류** — 기존 resolver 재사용, 기존 resolver의 매개변수 확장, 새 공용 `kind`, 상태 모델 선행 작업으로 나눕니다.
3. **상태 기반 완성** — Hidden/뒷면 정보, 토큰 소멸, XP·Level, Temporary, 죽음과 대체 효과, 턴당 최초/1회 표식을 먼저 고정합니다.
4. **선택·비용 계약** — 대상과 추가 비용을 플레이 전에 선언하고, 결제 실패·대상 이탈·거절 뒤 continuation이 정확히 한 번 이어지게 합니다.
5. **기믹 수직 구현** — 아래 표의 대표 카드로 정상·거절·불법·대상 이탈을 검증한 뒤 같은 효과군을 일괄 생성합니다.
6. **UI 연결** — Hidden 공개, 폐기장 사용, 복수 대상/모드, 서로 다른 Repeat 비용, 활성화 비용을 클릭 가능한 선택창과 비용창으로 노출합니다.
7. **비공식 한국어** — 219장 이름·유형·효과 본문과 새 선택지·상태 문구를 한국어 모드에 표시합니다.
8. **계약과 전체 검증** — 카드 행동 계약, 효과 커버리지, 상태 writer 기준선을 갱신하고 `npm run check:no-ai`만 사용해 전체 검증합니다.

## 세트 완료 조건

- 공식 본세트 219장과 등록 카드가 번호·비용·유효 문구 기준으로 정확히 일치합니다.
- 모든 인쇄 효과가 등록된 공용 resolver에서 소비되고, 미등록 `kind`나 카드 이름 분기가 없습니다.
- 새 선택·지불·반응·트리거 흐름이 온라인 명령 검증과 UI에서 동일하게 작동합니다.
- 모든 카드에 비공식 한국어 이름과 효과 본문이 있고 새 선택지에 번역되지 않은 핵심 동작 문구가 남지 않습니다.
- 대표 카드 집중 테스트, 상호작용 조합, 고정 시드 퍼즈, 생성 시나리오가 통과합니다.
- `npm run audit:set -- --set UNL --gallery spec/cards/unleashed-official-2026-08-29.json --skip-rules-check`가 219/219를 보고합니다.
- 최종 전체 검증은 AI 검증을 제외한 `npm run check:no-ai`가 통과해야 합니다.
